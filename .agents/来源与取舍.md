# agent-maintenance 接入记录

本仓接入 `WncFht/agent-maintenance` 固定版本 `20bb1e5b0cca68ca64c79451c19a0130f6281bb0`。维护材料源自 DeepSeek Harness 固定提交 `571902028a75c64c1d767f4ae5fd099485f0ddf0`，经过上游中文翻译、裁剪与重组；Python 检查工具由 agent-maintenance 提供。上游 MIT 许可完整保留在 [AGENT-MAINTENANCE-LICENSE](AGENT-MAINTENANCE-LICENSE)。[^upstream]

## 接入内容

- [maintain-docs](skills/maintain-docs/SKILL.md)：文档编写、重组与事实核验。
- [maintain-prose](skills/maintain-prose/SKILL.md)：正文、注释和诊断文字维护。
- [maintain-decision-notes](skills/maintain-decision-notes/SKILL.md)：长期决策记录的创建、更新、取代与封存。
- `references/`、`templates/` 和 [notes/](notes/README.md)：共享规范、文档骨架和 Agent Notes 生命周期。
- `scripts/check_docs.py`、`notes_guard.py`、`check_archive.py`、`staged_checks.py`、`run_checks.py`：维护检查入口。

## 适配边界

TeXlate 已有 Ruff、Prettier、Markdownlint、Shell、TOML、gitleaks、pytest、web 和 Zotero 检查，继续复用现有配置。维护检查额外接入提交、推送和 CI；本机生成目录与临时实验不纳入维护文档扫描。安装入口复用 `scripts/agent-links.sh` 与 pre-commit，不引入上游独立 venv 或替换产品依赖。

全部文档采用新维护规则。旧 ADR 的有效理由合并到 Agent Notes，当前契约、操作与证据分别归位；旧分区的整目录冻结和永久保留规则已移除。迁移依据见 [文档归并记录](notes/implemented/process/2026-10-16-文档归并.md)。上游自身的过程 Notes 不复制进 TeXlate。
