# Agent Note: 统一文档规则与主题归属

Status: implemented

## 问题

旧文档分区混合当前契约、实施计划和历史证据，逐层索引与目录全集重复维护。旧 ADR 与研究整目录冻结又阻碍有依据的合并。用户要求全部采用新规则，并尽可能精简现有文档。

## 决策

当前说明保留 guide、spec、dev；历史实验按主题归并至 research，有效决策理由进入 Agent Notes。删除重复清单、已完成工单、失效计划与无关调研；保留实验数据、图源和报告源文件。由 docs/README.md 统一导航，小目录不为凑索引增加 README。

这取代接入记录中“旧 ADR 不迁移”的局部决定，维护技能、许可、暂存快照与可信封存保护继续有效。普通报告可以核实后勘误和合并，只有 Notes archived 使用封存保护。检查器同时覆盖研究报告，并从统一入口检查文档可达性。

## 考虑过的替代方案

整体移动到 archive 会保留全部阅读与维护负担。按字数或文件数删减会丢失恢复、兼容和测量条件。继续维护旧 ADR 与新 Notes 两套生命周期会保留重复事实源，因此按内容归属合并。

## 后果

历史数字注明测量时点与覆盖缺口，不能当作当前版本复测。原文可从重构前提交 39bf31f0 恢复；逐文件归属见 .agents/doc-migration-2026-10-16.json，其中归并入口不承诺复刻过期内容。移动后的 Markdown、裸路径和代码注释同时修复；自动检查不能证明保留了全部行为语义，仍需审阅内容与差异。
