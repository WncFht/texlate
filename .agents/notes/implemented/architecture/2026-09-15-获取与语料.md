# Agent Note: 钉版获取与分层语料

Status: implemented

## 问题

arXiv 来源存在无源码、旧版本、格式差异和服务限流；单一渠道无法同时提供近期、完整和大规模免费源码。面向近期 CS 的负载也不能由历史均匀样本代表。

## 决策

产品采用钉版源缓存和 e-print、HTML、PDF 的显式降级，元数据与内容分别限速。共享 id 归一化以稳定原始标识和存储键，解包先执行安全限制。

评测保留概率核心、定向补强、近期与留出层，manifest 与物化载荷分离。按成员摘要钉住版本，有损文本渠道只承担明确允许的用途；保留取源失败作为分布信息。测试与开发不共享留出层的调参用途。

## 考虑过的替代方案

仅靠逐篇在线抓取不适合大规模构库；HTML 或文本重构不能冒充完整图像源码。扩大均匀样本不能代替稀有机制补强，混合定向样本后不加权池化会改变总体含义。未取得许可的译文不能因 arXiv 可下载就默认公开托管。

## 后果

样本、渠道和版本共同约束实验结论。源失败和编译失败需分开；不同年代或学科不能直接横比未经校准的成功率。数据源与抽样实验见 `docs/research/2026-10-16-获取与语料实验.md`，当前 manifest 约定由 `bench/corpus/MANIFEST.md` 维护。
