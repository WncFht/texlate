# Agent Note: 受控展开与区间回写

Status: implemented

## 问题

真实 LaTeX 含结构宏、正文内定义和畸形语法。能生成语法树不证明可译内容识别正确，重新序列化也不能保证注释、空白和原始宏调用逐字节保真。

## 决策

采用 Mouth、Gullet、Segmenter 分层的受控展开与 pieces 区间回写。展开产物只用于分类，splice 使用调用点源字节；块边界和引用等结构留在保护侧。定义按出现顺序生效，不加载真实宏包执行任意 TeX。

未知或超预算结构保守保护并保留诊断；条件结构按已知语义处理，不实现完整 catcode 和 TeX 求值器。正确性由 identity、占位符多重集、源译相对规则、可选 CST 与编译日志分别验证，不能用 PDF 存在作为唯一证明。

## 考虑过的替代方案

完整 AST 重建会改变原始表示，严格解析在脏语料上失败；plasTeX 加载宏包引入求值、耗时和截断风险。先收集全部定义的两遍展开会把后续重定义错误应用到先前调用。tree-sitter 绝对 ERROR 判定对原稿文法缺口大量误报，因此采用相对 baseline。

## 后果

保守保护允许漏译，优先避免正文损坏。半解析没有完整 TeX 语义保证，新宏族需要语料与反例验证。历史解析和校验实验见 `docs/research/2026-10-16-解析与校验实验.md`；当前契约见 `docs/spec/latex-pipeline.md` 和 `docs/spec/validate.md`。
