# Agent Note: 双引擎与可复现修复

Status: implemented

## 问题

tectonic 的便携性不能覆盖 EPS、字体与旧 bundle 的全部限制，系统 XeLaTeX 又依赖较重环境。编译器即使产生 PDF，也可能丢字、丢图或静默降级。

## 决策

保留双引擎、静态路由和实际日志判定。ctex 注入与源码归一化使用屏蔽视图定位，条件修复留给 fixloop；两层不重复改同一位置。LaTeX 2.09 先尝试受控升级，无法支持时明确降级，不强注 ctex 后假报成功。

fixloop 以规则、案例与最小补丁沉淀修复。CTAN 拉包只处理输入层文件，需校验新包与旧 bundle 的内核兼容；物理字体和图形能力另行处理。vendor 原件须有分发许可，不可分发宏包采用明确的替身实现。

判定结合文件存在、日志红线与中文文本证据，版面质检独立。执行边界使用 TeX 安全选项、环境限制、可用系统沙箱和进程树超时；缺少 OS 沙箱时不能声称具有同等隔离。

## 考虑过的替代方案

单引擎会失去互补覆盖。盲删 vendored 宏包可能删掉唯一依赖；盲拉最新包会引入内核不兼容。无条件执行模型补丁缺少可复现性与安全边界，因此补丁要求工作区内目标和精确源匹配。

## 后果

修复可能改变排版，出 PDF 不等于内容与版面完整。失败证据与已付费译文须保留以便零重复调用重放。历史实验见 `docs/research/2026-10-16-编译与修复实验.md`，当前行为见 `docs/spec/compile.md`。
