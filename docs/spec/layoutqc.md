# 版面质检与保留契约

`bench/py/specs/_layoutqc/` 对编译 PDF、日志、源环境与标记进行质检。编译成功、翻译完成和版面无缺陷是不同判断，不能互相替代。

## 输入与判定

质检以原文基线与译文对照，结合 PDF 可读性、编译完整性、标记与环境覆盖、文本退化、几何和墨量等信号。源文件已有的缺陷应在同口径基线中抵销，不能全部归因于翻译。

`thresh.py` 集中保存阈值与 HARD/WARN/INFO 信号集合。HARD 表示交付完整性或严重缺陷，阻断 done 并保留诊断材料；WARN 计入质量分但不阻断交付；INFO 只记账。新信号未显式归类时按 WARN，不自动升级成硬拒绝。clean 要求零非 INFO findings。

## 检测边界

| 层面       | 证据与限制                                                                   |
| ---------- | ---------------------------------------------------------------------------- |
| 编译完整性 | PDF 存在与可读、截断、缺图、源环境和浮体标记覆盖                             |
| 内容       | CJK、残英、空页、重复与替代字符；不能替代语义翻译评估                        |
| 几何       | 越界、重叠、浮体丢失与漂移、列坍塌；需容忍原稿缺陷与字体 bbox 噪声           |
| 渲染       | 墨量、缺字框、文本曲线化等代理信号；不能保证公式视觉等价或表格 cell 结构正确 |

重排导致页数和浮体顺序变化本身不是错误；匹配应使用适当窗口与基线。水印、页眉、图内文字、曲线化文本和 PDF clip 会影响几何统计，检测器必须明确纳入和排除条件。

## 工件与恢复

仅在结果达到保留策略要求时精简免费工作区。质检失败保留足够的源、日志、splice 和 PDF 用于回放；付费译文真身由 vault 管理，不因质检无缺陷就删除。

回放使用副本，不能覆盖 vault 原件或修改历史 run。检测器版本与阈值变化后的复测必须独立注明口径；不得把修后复测写成原运行的历史读数。存储与付费裁决见 [bench-trizone.md](bench-trizone.md)。

## 验证

对每类检测器使用真实缺陷正例、接近阈值的无害反例、原稿对照与回放错误统计。版面实验与浮体修复结果见 [端到端评测](../research/2026-10-16-端到端评测.md)；当前信号集合以 `thresh.py` 和所属测试为准。
