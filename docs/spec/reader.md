# 阅读器交互契约

阅读器以 SolidJS 与 pdfslick/pdf.js 组合 PDF、HTML 与翻译进度视图。服务端行为见 [server.md](server.md)，位置映射见 [reader-alignment.md](reader-alignment.md)。本文只描述实现的跨组件约束。

## 选区与命令

各 pane 使用原生 Selection；命令注册表统一工具条、右键菜单与键位入口。命令根据命中语境与能力显示，不能对没有源码的视图承诺 LaTeX 文本复制。拖选时抑制浮条，松手后定位；失焦与 pointercancel 必须释放拖选态。跨 pane 选择按各侧分别解析，不能使用跨栏 union rect 定位工具条。

Esc 使用层栈关闭最上层交互，输入控件中的编辑键不能被全局导航误消费。键盘 focus 与指针 hover 分开处理；悬浮卡需支持焦点移入、Esc 关闭和合理的离开宽限。

## 引用与导航

同一引用锚的 hover 显示条目，click 执行跳转；触屏 tap 先打开卡片，由卡内动作跳转。滚动、缩放与页面销毁释放卡片。开卡 dwell 与关闭宽限由实现常量维护，不在多个组件各自定义。

每 pane 一份内存导航栈；滚动不入栈，真正导航记录跳前活态。不能使用会修改浏览器 hash 的 PDFHistory 驱动 SPA 内跳。PDF 内链经 linkService 跳转入口串行执行，过期导航可作废；目的地不存在或跳前后位置相同，不得生成幻影栈项或截断前进记录。

split 模式可将刻意导航镜像到对侧；成对跳转具有共享标识，返回时各侧恢复自己的跳前位。该配对与日常滚动同步开关分离。目标 pane 尚未就绪时延后投递，较新的导航覆盖旧请求。

## 引用内容、收藏与翻译

卡片先使用本地条目：dual 占位符中的 bibitem、PDF 目的地附近文本或 HTML 文献节点。元数据为机会型增强，由服务端代理 S2 与 Crossref；浏览器不随 hover 直接打上游。命中缓存与负缓存分别限流；上游故障返回降级结果，字段缺失隐藏，不能阻断本地阅读。

收藏在 SQLite `kept_refs` 中按 task 与 ref key 保存当时条目快照。任务瘦身或后续文本重排不能把用户标记静默丢弃。`.bib` 导出先尝试源包原始 BibTeX，缺少结构化源时由快照合成；任务删除按其生命周期清理收藏。

引用能解析出 arXiv id 时可创建文献翻译任务。重复活跃任务可收养，失败终态可重试；按钮须接受终态重新进入执行态。没有实现选区翻译/词典 API，不展示该能力为现成功能。

## LaTeX 复制

`POST /api/task/{task_id}/latex` 根据 seq、源文件 span 与可选选区锚返回切片。租户闸与源可用性先行；`arxiv_html` 没有原始 TeX，返回 `no_latex_source`。源树、源归档与派生数据的回退由 `server/srccut.py` 实现，不从渲染文本伪造逐字源码。

原文选区可使用句界裁剪或整段模式；译侧无法在异语言源文中确定字符偏移，回退整段。PDF 模糊命中只能提供有证据的粒度，响应中的 `approx`、`truncated` 与 `mode_used` 必须如实展示或消费。

公式优先从 MathML alttext 或 KaTeX annotation 取源；近似重构须显式标识。源码卡使用 textContent 等文本写入，不能把论文中的 LaTeX 当 HTML 插入。完整宏定义打包与 PDF 字形反推公式均不是默认保证。

## 外观

色板是全站统一外观状态。命名色板决定纸面与界面配色，auto 跟随系统；none 保留原纸并使用系统界面明暗。旧 theme 键只用于迁移，不维持第二套独立主题轴。

PDF 页面改色通过 document 实例级渲染包装接入，不修改全局 canvas 原型、不 fork pdf.js。彩色图、照片与扫描页分别处理；切换外观使页面与缩略图重新渲染。原色模式保留为排障入口，不能把视觉改色等同于修改下载 PDF。

## 验证

运行 `web/` 的类型检查、lint、Vitest 与构建；导航、选区、复制、主题还需对应浏览器验证。源码契约与跨 pane 时序分别检查，单纯截图不能证明导航栈或源码切片正确。
