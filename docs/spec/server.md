# 服务端与渠道契约

FastAPI 应用由 `server/app.py` 装配，路由、SQLite store 和任务 worker 分层。HTTP schema 可从运行服务的 `/openapi.json` 查询；这里说明跨模块语义，不复制完整字段清单。用户配置见 [BYOK](../guide/byok.md)，阅读器消费契约见 [reader.md](reader.md)。

## 任务与事件

任务输入包括 arXiv 源码、上传源码、HTML、PDF、电子书与共享包；worker 按 kind 选择管线。LaTeX 臂消费 `pipecore/` 共享步骤，避免 API、CLI 和 bench 各自维护翻译与修复策略。

任务状态包括 `queued`、`fetching`、`parsing`、`translating`、`compiling`、`done`、`partial`、`fault`、`cancelled`、`interrupted`、`needs_auth`。`partial` 允许降级产物，不能当作完整译文或无缺陷 PDF 的证明。重试可让终态任务重新进入执行态；客户端不能把首次终态当作任务永久结束。

任务快照与 SSE 事件共享 task id；事件序号用于断线重放，终态重试保留同一任务标识。进度展示必须按阶段与轮次解释计数，不能把 `done/total` 当跨阶段单调百分比。单块重译保留源 span，更新译文后重新装配相应产物。

同缓存键的活跃任务通过去重槽防止重复消费；`duplicate_active` 返回现存任务，客户端可收养其 task id。缓存键与共享格式由 `share.py` 定义，不能在客户端自行推算替代服务端值。

## 认证与隔离

`local` 模式用于本机，依靠回环对端与 Host 校验；绑定非回环不提供完整的多用户认证保证。`server` 模式通过 `X-Texlate-Key` 认证写操作，任务访问还经过租户检查；知道 task id 不等于获得访问权限。

请求 BYOK 覆盖仅用于对应请求或任务，不得作为明文写入事件、日志和产物。渠道配置属于部署拓扑，`server` 模式关闭渠道 API 与 settings 写面。公开 settings 读面只暴露允许字段。

上传按流式体积限制落盘，按魔数分类；源码解包执行路径、链接、成员数量与展开大小限制。产物下载使用白名单 kind 和登记路径，不能拼接任意请求路径。远程取源与重定向也须经过网络目标策略。

## 渠道持久化与凭据

`server/channels.py` 是 HTTP、CLI 和 worker 共享的数据层。`channels.json` 为 version 2，原子写入且文件权限为 0600。配置包括渠道、模型与单一路由选择；`settings.json` 只保存任务策略和外观等字段。

渠道 id 创建后稳定，不随 URL 修改。模型的本地名与上游重定向名分开：展示、选择使用本地名，请求使用 `wire_model`。`api_key` 与 `key_env` 互斥，后者仅保存环境变量名。写入空 key 保留同 id 旧值，切换凭据形态时清除另一形态。探测摘要由服务端维护，客户端载荷不能伪造该状态。

首次缺少渠道文件时，bootstrap 合并旧端点档、settings 中的 BYOK 键与连接槽；旧文件迁移留档，settings 移除 BYOK 键。此后旧源不再参与日常路由。迁移保留旧凭据与去重语义，不能因文档清理撤掉兼容路径。

## 路由、并发与冷却

自动路由优先级大者优先，过滤停用和冷却组合。指定模型时先找显式包含该本地名的渠道，无法匹配时使用可用默认选择。钉渠道限制候选渠道；失败回退与模型重定向均由同一数据层决议。

渠道级传输或认证故障与模型级限流、服务错误分别记冷却。冷却采用进程内 monotonic 到期戳，重启清空，不等于永久禁用。并发限制包含全局、渠道和模型约束，客户端显示模型清单不代表全部模型当前可用。

## 产物与清理

files 表登记产物种类、路径与摘要；下载方可按 sha256 验证内容。中文 PDF 缺席时仍可能交付译后源码或诊断材料，不能仅以任务终态推断全部文件存在。

保留期与容量清理面向终态任务。任务目录中的未登记 sidecar 可能被瘦身删除；用户收藏因此使用数据库快照，不依赖临时展开树。任务删除同时清理相关行和目录，恢复、取消与清理都应停止新工作并等待已有工作结束后释放资源。

## 验证入口

`tests/server/` 覆盖租户、上传、路由、事件与渠道语义；`scripts/server-smoke.sh` 验证真实 HTTP、SSE、产物清单和下载摘要。外部模型探测会产生实际请求，不能以静态 schema 验证代替。
