# 双语位置与源码锚定

阅读器的位置映射同时服务滚动同步、引用镜像、选区定位与句级高亮。位置证据的粒度必须随来源保留，不能把页级插值解释为逐字对齐。

## 数据来源

原文与译文 PDF 由同一源码体系编译时可按 named destination 配对。官方 PDF 的排版和锚名可能不同，不能直接借用自编译 PDF 的锚位。`align.py` 生成配对与插值信息；HTML 分块则可使用 DOM 的块标识。

译后源码通过 `latex/reconstruct/` 注入 marked-content seq 标记，PDF BDC/EMC 不是可见字符。环境、移动参数、表格和宏展开会影响标记裹住的字形，不能仅以标记存在认定位置可信。

`server/seqpos/` 从标记与文本恢复 `{page, fraction, x?, x1?}`；page 的具体编号约定由接口消费方统一，内部变换不得暗自加减。解码与缓存契约见 [seqpos-decoder.md](seqpos-decoder.md)。

## 可信与回退

优先使用可信实标，覆盖不足时执行有界文本匹配，再考虑插值。目录重放、运行页眉、空壳标记、数学字形和双栏阅读序均可产生伪命中；有效候选必须同时满足文本与空间条件。

没有证据的段可无锚，死区与未译段不应被强行吸附到邻段。对侧没有真值的位置不进入精确对齐评测分母。横坐标用于判栏和行内位置，不能仅按 y 最近选择目标。

## 前端消费

同步引擎区分用户滚动、程序导航与镜像窗口，避免两栏循环驱动。引用导航采用成对历史，不以一次 scroll 事件替代导航完成。pane 暂未就绪时缓存最新镜像请求；过期异步结果不得覆盖新位置。

句级同步消费 seq 对应关系；LaTeX 复制还需源 span，不能直接把中文选区字符偏移套进英文源。PDF 文本层模糊匹配是降级路径，需限制搜索范围并保留近似标记。

## 测量

验证分别报告点击选中率、页正确率、指定误差以内的端到端正确率、无锚率和选错段数；没有对侧真值的比例另报。仅 reporting 命中率会掩盖错栏和错段。

度量脚本集中在 `tools/seqpos_*`。历史实验归 [对齐与阅读器实验](../research/2026-10-16-对齐与阅读器实验.md)，数值均为对应样本与版本的证据。
