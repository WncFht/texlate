# 使用指南

TeXlate 把 arXiv 论文的 LaTeX 源码逐段交给大语言模型翻译，再重编译出中文 PDF，并提供双语对照阅读器。本分区写给使用者：从安装到日常操作都在这六篇里，每篇独立成立，可以按问题直接进入。

## 索引

| 文件                              | 内容                                                                     |
| --------------------------------- | ------------------------------------------------------------------------ |
| `quickstart.md`                   | 安装到第一份双语 PDF：依赖、引擎、自检、mock 干跑、真翻译                  |
| `cli.md`                          | `texlate` 全部子命令参考：旗标、退出码、环境变量、日志与离线模式           |
| `web.md`                          | `texlate web` 服务与阅读器界面：提交任务、上传、任务状态、对照阅读、下载   |
| `byok.md`                         | 自带 API key：三种配法、端点要求、模型与方言选择、并发与缓存行为           |
| `export-share.md`                 | EPUB/DOCX 双语插译导出；`.share.zip` 共享包的打包与解包                    |
| `faq.md`                          | 编译失败、占位译文、离线、支持范围、并发、数据存放位置等常见问题           |

## 新读者路径

第一次接触 TeXlate，按 `quickstart.md` 走完一遍即可：装好依赖后先跑一次 mock 干跑确认识别与编译链路正常，再配置自己的模型服务开始真翻译。

之后按使用形态分流：日常在浏览器里提交论文、对照阅读、下载产物，读 `web.md`；要写脚本批量处理或接入远端服务，读 `cli.md`；要调 key、换模型、改并发，读 `byok.md`；要处理电子书或与他人互换译文缓存，读 `export-share.md`。任何一步卡住，先翻 `faq.md`，再跑 `texlate doctor` 对照环境检查项。
