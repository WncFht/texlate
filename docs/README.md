# TeXlate 文档库

TeXlate 是「幻觉翻译」（hjfy.top）的开源复刻：arXiv LaTeX 源码 → LLM 段落级翻译 → ctex 重编译中文 PDF，双语对照阅读。本仓即 texlate 主仓，`docs/` 分区为项目的完整文档库——使用指南、技术规范、决策记录、调研档案与工程日志（产品代码见 `src/`、`web/`、`bench/`）。

## 文档地图

| 分区             | 读者   | 内容                                                         | 生命周期                                                       |
| ---------------- | ------ | ------------------------------------------------------------ | -------------------------------------------------------------- |
| `guide/`         | 用户   | 安装上手、CLI、web 服务、BYOK、导出共享                      | 活文档，随版本更新                                             |
| `spec/`          | 实现者 | 各层技术规范，**实现的唯一事实源**                           | 活文档，与代码现状对齐                                         |
| `decisions/`     | 所有人 | ADR 决策记录：为什么这么定                                   | 只增不改（子结论改判走宿主 ADR「演变」节）；整篇作废才开新 ADR |
| `dev/`           | 贡献者 | 仓布局、工具手册、评测协议、自动化契约                       | 活文档                                                         |
| `research/`      | 实现者 | 调研与实证档案，决策的证据层                                 | 写完冻结，可加状态注记                                         |
| `log/`           | 所有人 | 工程大事记与里程碑档案                                       | 只增不改                                                       |
| `MAINTENANCE.md` | 维护者 | 本文档库的维护规则（分区生命周期、格式、敏感政策、索引登记） | 活文档，写/改任何文档先读                                      |

阅读序：想了解项目 → 本页 → `decisions/background.md`；想用起来 → `guide/quickstart.md`；想改代码 → `dev/repository.md` → `spec/`；想查证某决策依据 → `decisions/README.md` 索引 → 对应 ADR → `research/` 证据件。

## 维护约定

详见 `MAINTENANCE.md`。要点：`spec/` 是实现的唯一事实源、与代码对齐；新实证进 `research/` 并登记索引；子结论改判记宿主 ADR「演变」节，整篇作废才开新 ADR 而非改写旧文；外部引用一律脚注加参考文献节；本库公开发布，禁入 key/内网地址/本机路径。
