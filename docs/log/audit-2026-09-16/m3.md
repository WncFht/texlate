## 跨里程碑集成缺口（影响"一键可用"实际质量）

- **fixloop 未接入 server 管线**：`_compile_zh` = `engine.compile` 单次 + `judge`，不跑修复环。M2 攻坚成果（25 条 yaml 规则、tlmgr 装包、ctan_fetch）在 web 路径全部不生效，web 侧编译成功率将显著低于 compilebench 口径（fixloop 臂 70.6%→89.5% 的净收益拿不到）。
- `REDIS_URL` 队列后端未实现（裁决 4 注明"M0 不实现 huey"，属按计划 deferred，但 §5.10 server 形态提到 Redis 队列——server 模式部署项缺）。

> 注记（勘误）：上节「25 条 yaml 规则」为 09-15 初移植口径——本审计同日 m2/docs 分报告实测 `rules.yaml` 为 31 条（当日尾盘已增至 47）。

## 结论

M3 约半程。server 内核（FastAPI+SSE+SQLite 单写者+BYOK+worker 管线 + 断点恢复）是真实完整实现、104 用例全绿，质量高于"骨架"预期；前端代码同样完整且有 vitest 覆盖。**断在交付与外围**：SPA 不进包也不落 static（`texlate web` 起服后 `/` 404）、BabelDOC 只到"能 spawn"级、HTML 降级/EPUB/DOCX/Docker/tectonic 分发矩阵/单实例锁/瘦客户端/retry-model/tenant 配额均未实现，fixloop 未接 worker。出口判据"hjfy §1 对齐表全绿 + `texlate web` 一键可用"不成立——10 个 M3 行约 5 绿、3 半、2 红。
