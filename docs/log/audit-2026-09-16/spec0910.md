## 7. 偏差与缺口清单

1. **corpus_v2 计数过期**：spec/CLAUDE.md 写 137/223，实际 manifest ok=139、.tex=224（语料在冻结后扩了 2 篇）。
2. **corpus_v2 折入核心层未按 spec 实现**：docs/09 §1 说折入后 `channel=direct-fetch` 进 manifest 做渠道敏感性——manifest.jsonl 实际只有 ia/tiger，v2 仍是独立语料分开跑（敏感性检查仍可事后做，但 manifest 无该 channel 行）。
3. **manifest schema 漂移**：S4 schema 要求行含 `features`，实际 manifest.jsonl 无该键（features 在 per-paper `meta.json`）。
4. **B3 zh/mock 条件缺位**：compilebench 网格只跑过 base 原文臂；M2 门"200 篇 zh ≥90%"无对应测量（最近似=base+fixloop union pdf 89.5%，n=172）。
5. **e2e Mode B 未产品化 / Mode C 未实现**：spec 自标 Mode C"待跑"；Mode B 的校验兜底职责事实由 B6 validbench 接管，但 B5 harness 本身无幻觉注入臂。
6. **flatten coverage 字面门未过**：94.4–94.5% < 99%，靠 §8 表下勘误口径（≥93%/排除 unreferenced）过——门表本身未改写。
7. **B7 门当前 FAIL**：alignbench e2ereal 对 2 ERROR + 保留率含 0.026 离群对（M3 前待办，非 M0 阻塞）。
8. **oracle 对拍探针未扶正**：`oracle_extract.py`/`oracle_diff.py` 不存在，仅 `tmp/exp/oracle/oracle_probe.py`（spec 定位非 gate，影响低）。
9. **产出契约小漂移**：docs/10 §8 统一三件套约定 `files|cases.jsonl + papers|cells.json + summary.md`——e2emock 用 `results.json + matrix.md`，xlatbench 用 `results.jsonl + models.json`（语义等价、命名不一）。
10. **spec 路径误差**：`tests/latex/test_bench_regression.py` 实为 `tests/test_bench_regression.py`；spec B2 记"54 用例"实为 98。
11. **reject 判定正确率 100% 无金标准对拍专测**：B1 路由标签与 B3 判定的对表只体现在 compilebench §3 route 实录 + HANDOFF 假阳性注记，无专项指标输出。
