\subsection{语料分层构造}
\label{sec:corpus}

\subsection{门槛体系}

各臂门槛（\texttt{docs/09} §8）：parsebench——parse ok 100\%、identity $\geq 99.5\%$、leak $\leq 0.15\%$、dead$\cdot$orphan $=0$、flatten $\geq 99\%$；M2 出口门（stagerun scorecard）——union pdf $\geq 90\%$、clean $\geq 90\%$。统计口径：核心层加权池化率 + 宏平均双报，Wilson + 月簇稳健 bootstrap CI。
