\subsection{评测现场：\texttt{bench/} 的构成}

\subsection{语料分层构造}
\label{sec:corpus}

corpus\_v3 是钉版批量语料：每个 cell 记录 \texttt{(channel, item, member, blob\_sha256)} 四元组钉住字节级来源（\texttt{resolved\_version=null}），落地为 \texttt{\{id\}/} 目录（\texttt{meta.json}、\texttt{raw.*}、\texttt{extracted/}）。四条渠道各有明确分工：\texttt{ia} = IA \texttt{arxiv-bulk} 月度 chunk（a--d 时代带主力，覆盖至 2020-10）；\texttt{tiger} = HF \texttt{TIGER-Lab/arxiv-latex-5T}（e 带主力，成员截止 2412 月）；\texttt{arxiv\_eprint} = 单发 e-print 取源（走产品 \texttt{acquire\_source}，补 TIGER 截止后 2501+ 盲区）；\texttt{hf\_scholarweave} = scholarweave 脱水通道（\texttt{figures\_stripped} 有损源——解析/翻译段可用，编译段因缺图源排除）。全库 13{,}266 cell、raw blob 18.8GB（含 \texttt{extracted/} 解压树全库约 46GB）。八层构成见图~\ref{fig:corpus}、分层定位见表~\ref{tab:layers}：核心/补强/扩展/热层为早期层，2026-09-19 评测/开发分轨扩层后收至 13{,}266 篇。

\subsection{逐臂详解}
\label{sec:arms}

\subsubsection{B1 parsebench —— 解析正确性}

\textbf{测什么}：\texttt{texlate.latex} 半解析器对真实语料的正确性——能不能零崩溃、能不能逐字节还原、可译 chunk 里有没有漏进受保护内容。

\textbf{harness}：逐文件 30s 超时，主文件定位 $\to$ flatten $\to$ \texttt{parse\_file} $\to$ \texttt{reconstruct()} 三连测——strict identity（逐字节一致）、空译文 fake-translate（dead/orphan 占位符探针）、占位译文（leak 探针）。\texttt{files.jsonl} 逐文件落盘，\texttt{papers.json} 逐篇聚合，产出路由标签（reject / xelatex / minted / non-utf8 / no-hyperref——\textbf{同时是 B3 的静态路由金标准}）与 flatten 覆盖、multi\_doc/rootless 标记。统计口径为核心层加权池化 + 宏平均双报、Wilson + 月簇稳健 bootstrap CI；另有 oracle 对拍探针（plasTeX 规范化文本流 vs chunks 的字符级 recall），仅作开发期召回探针不进 gate。异常逐条人工归因写回机制台账。

\textbf{当前读数}：28{,}904 文件 parse ok 100.0\%、strict identity 99.99\%、leak 0.004\%（图~\ref{fig:parse}、表~\ref{tab:snapshot}）。

\subsubsection{B2 fixtures —— 机制断言集}

\textbf{测什么}：parsebench 测分布，fixtures 测机制——「这个具体的坑处理了吗」逐条断言。

\textbf{底材}：10 件手构 \texttt{.tex}（tricky 主集 + 209 旧格式 + multi 多文件工程 + w/w73/wenc 野外机制件 + xlat-traps 翻译层），\texttt{@Tnn}（结构陷阱）/\texttt{@Wnn}（野外发现机制）/\texttt{@Xn}（翻译层）三族标记；\textbf{逐字节即语义}，永不格式化。\textbf{生长机制}：parsebench 归因与台账 \texttt{found-in-wild} 条目达到 covered 后提取 fixture 化——语料里每个真坑沉淀为永久断言，断言面只增不减。

\textbf{当前读数}：98 用例 pytest 全绿（L0 层 CI 硬门，断言函数与 \texttt{fixture\_assert.py} 共享）；BUG1 ph 尾回归断言实测 0。

\subsubsection{B3 compilebench —— 编译与 fixloop 救回}

\textbf{测什么}：normalize + ctex 注入 + 引擎 + 修复循环的真实救回能力——hjfy $\sim$5{,}000 篇人肉沉淀护城河的对应物。

\textbf{harness}：paper $\times$ condition $\times$ engine 网格——condition $\in$ \{base 原文 / zh 注入 / mock 译文\}，engine $\in$ \{xelatex, tectonic\}；路由预检先行（\texttt{documentstyle}$\to$reject、eps/pstricks$\to$xelatex、minted-frozencache$\to$tectonic）。每格 normalize $\to$ inject $\to$ 沙箱编译（$\leq$2 pass、240s）$\to$ fixloop $\to$ clean 判定三件套；逐格 verdict + 每轮 \texttt{\{cat,pay,rule,result\}} 落盘直灌机制台账。归因按首错 sig 聚类（verdict\_sig 口径：构成中计数最高的 cat 超过首错 cat 时改挂该众数 cat）。指标：clean 率（分 condition/引擎/时代带）、fail$\to$pdf 救回率、规则 fires/rescues、stuck 率、修复轮数分布。

\textbf{门槛}：200 篇 zh 条件编译成功率 $\geq$90\%（hjfy 95\% 为渐近线）、reject 判定正确率 100\%（路由标签对拍）、无回归（clean 格不被规则改脏）。

\textbf{当前读数}：n=500 联合 pdf 90.4\%（图~\ref{fig:compile}）；zh 臂 xelatex clean +16.1pt——normalize 顺带修复源缺陷，产品链成本转正收益。

\subsubsection{B4 xlatbench / qualbench —— 翻译契约与质量}

\textbf{B4a 硬契约层}：chunk $\times$ model $\times$ repeat 网格，chunk 按 kind 分层抽样（para、caption、item、footnote 外加 stress 压力样例——\verb|\bibitem| 前缀、\verb|\href| 等陷阱位）；每响应过 L0 validator，指标按序读——硬契约率（丢/造占位符、丢脆弱命令、validator error）$\to$ ord 软信号（合法中文换序不降权）$\to$ 延迟 $\to$ reasoning $\to$ token 经济。用途是模型选型/白名单刷新（免费集 promo 到期即重跑）与 prompt 措辞回归（bump prompt\_version 必跑）。

\textbf{B4b qualbench 质量层}：LLM-judge（esa2 协议）对段对打 stated100 分 + 错误分类 $\times$ severity 三级（terminology/fluency/accuracy/convention/non-translation 五族九类 flag）；judge=swe-2-max，分歧判例记 contested 由 swe-2-high 二裁；产出 mean/median、分数段分布、per-kind/per-paper 细分。门槛 M1：100 篇真实翻译端到端 $\geq$85\%。

\textbf{当前读数}：hard\_ok 93.7\%（254/271）、ESA mean 94.0 / contested 5.5\%（图~\ref{fig:qual}）。

\subsubsection{B5 e2ebench —— 全链组合}

\textbf{测什么}：单段绿不等于组合绿——逐环节成功率漏斗 + 终态分布。四模式：\textbf{Mode A} 位置忠实 mock（占位译文走全链验机械链路：PDF/identity/零残留占位；已知盲区：mock 只认 ASCII 散文 run，非 ASCII 散文原样回显会过估忠实度，真译臂不受影响）；\textbf{Mode B} 幻觉 mock（注入占位符丢失/幻觉破坏验校验链兜底——132 处破坏编译前 132/132 捕获，「出 PDF $\neq$ 成功」的实证来源）；\textbf{Mode C} 位置扰动 mock（随机移 $\sim$10\% 占位符量化 splice 鲁棒性）；\textbf{Mode D} 真实翻译接入（产品 SLA 观测点）。另有 \textbf{pipe-fix 救回臂}：pipe-xel 产物树进 fixloop 复判，union 取 pipe-xel/pipe-fix 较优者；\texttt{onfail} 语义经冒烟校准为 fail + misschar/error 级 partial（partial 已出 PDF，fixloop 的引擎重跑只会丢 PDF 救不了 warning），inject reject 不救。

\textbf{当前读数}：mock 臂 pipe-xel 33/39 clean vs base 19/39（管线净正 +14）；real n=60 union pdf 96.7\%、splice 残留 0、0 管线引入回归。

\subsubsection{B6 validbench —— 校验器自检}

\textbf{测什么}：L0/L1 校验器对 LLM 破坏的检出能力——校验器本身必须被评测（实现期真抓到过校验器自身 bug）。

\textbf{harness}：变异器对干净 chunk 施 10 类破坏（丢 \texttt{\}}、丢 \texttt{\$}、\verb|\end| 改名/删除、丢/拼错/多余占位符、\verb|\[| 不配对、幻觉宏、删 cite key）$\times$ ph/raw 两层生成 \texttt{cases.jsonl}；另加对抗手工探针（掉 \verb|\emph| 组、占位符换序、\verb|\cite {k}| 带空格、漏 key、全角占位符等合法改写的边界断言）。指标：检出率（按破坏类分列命中规则）、error-FP（干净对）、warn-only 率、延迟/对、lev$\leq$2 修复建议率；L1 tree-sitter 层同口径。B4 的真实失败案例反向喂 B6 沉淀新破坏类。

\textbf{门槛}：10 类破坏 100\% 检出、干净对 0 error-FP、L0 $\leq$1ms/对。

\textbf{当前读数}：corpus\_v2 1{,}503 对全绿（摊薄 0.374ms/对）——本批未重跑，列缺口清单第 7 项。

\subsubsection{B7 alignbench —— 锚点保留}

\textbf{测什么}：zh 重编译后 named-destination 锚点保留率——双语滚动同步的质量上限。

\textbf{harness}：pypdf 提取双侧 named destinations $\to$ 同名锚点配对 $\to$ 保留率 + 最大权值单调链权重（section 12 / figure 10 / equation 4 / cite 2，\texttt{page.*} 权 0）。无 hyperref 工程（语料 $\sim$31\%）走退化路径断言不崩；\textbf{保留率 $<$95\% 本身可当 zh 编译完整性探针}（ctex 共享计数器改 theorem 锚名即由此捕获）。

\textbf{门槛}：有 hyperref 对保留率 $\geq$95\%；无 hyperref 对退化路径不崩。

\textbf{当前读数}：812 对门全过但覆盖薄——765 对 named-dests 为 0，有效读数仅 42 个 hyperref 对（retention p50=1.0），口径待复核（缺口清单第 3 项）。

\subsubsection{辅助件}

stagerun 五段批量 DAG（records append-only + \texttt{(id,arm,upstream)} resume + 网关信号量）与 \texttt{gate\_scorecard}（M2 出口门，union=compile$\cup$fixloop 阶段并集取优）；\texttt{translators\_bench} mock 臂工厂（mock / sabotage-b/c / perturb）；\texttt{gullet\_bench} 展开机实测（n=200 全展开 median 39.6ms/19 steps）；\texttt{triage}（records$\to$tickets 聚类）、\texttt{status\_panel}、\texttt{nightwatch}、\texttt{rundiff}、\texttt{wave}、\texttt{stage\_timing}、\texttt{preflight\_batch} 监控与批前闸。

\subsection{门槛体系}

各臂门槛（语料规格 §8，随档 \texttt{refs/}）：parsebench——parse ok 100\%、identity $\geq 99.5\%$、leak $\leq 0.15\%$、dead$\cdot$orphan $=0$、flatten $\geq 99\%$；M2 出口门（stagerun scorecard）——union pdf $\geq 90\%$、clean $\geq 90\%$。统计口径：核心层加权池化率 + 宏平均双报，Wilson + 月簇稳健 bootstrap CI。
