# 流程图 skill 调研（2026-09-19）

> **结论**：官方生态不存在任何流程图 skill；社区以 `WH-2099/mermaid-skill` 与 `Agents365-ai/365-skills` 最值得关注；自造 skill 时推荐 d2 为主渲染器、graphviz 兜底、GitHub/网页内嵌场景直接产 mermaid 源码块、TikZ 仅用于 LaTeX 正文内嵌图。
> **状态**：时点证据（2026-09-19 口径）
> **日期**：2026-09-19

目标：回答「有没有现成的画流程图 Agent Skill 可用」，范围覆盖官方生态、社区生态、以及自造 skill 时的底层工具选型。调研方式为三个并行 subagent 分路查证（官方仓/社区仓/工具面），下述条目均为当日核实后的事实。

## 官方生态盘点

`anthropics/skills` 仓（即官方 plugin marketplace「anthropic-agent-skills」本体）共 19 个 skill，无一覆盖流程图：academy-guide、algorithmic-art、brand-guidelines、canvas-design、claude-api、discernment-nudge、doc-coauthoring、docx、frontend-design、internal-comms、mcp-builder、pdf、pptx、skill-creator、slack-gif-creator、theme-factory、webapp-testing、web-artifacts-builder、xlsx。[^anthropic-skills] 沾边但不算的三个：`pptx` 只处理 PowerPoint 文件内部的原生 chart/SmartArt；`canvas-design` 面向海报/美术 PNG；`algorithmic-art` 是 p5.js 生成艺术。

Claude Code 内置 skill（官方文档列举）：/doctor、/code-review、/batch、/debug、/loop、/claude-api、/workflow-authoring、/run、/verify、/run-skill-generator、/skill-doctor，亦无画图类；文档中的 `render-chart` 仅是 SKILL.md 写法教学样例，不随发行版提供。[^cc-skills-doc] 官方插件市场 `anthropics/claude-plugins-official` 共 46 个插件（LSP、code-review、feature-dev、playwright、serena、terraform、asana/linear/github 集成等），无 diagram/flowchart/mermaid 项。[^plugins-official] 结论：官方路径下要画图只能自造 skill（官方提供 `skill-creator` 脚手架）或采社区方案。

## 底层工具面

调研时点开发环境上 `mmdc`、`d2`、`dot`、`plantuml`、`drawio` 均未安装；无 chromium、无 java；有完整 TeX Live（xelatex/tectonic，TikZ 可用）与 CJK 字体。各工具当日核实如下。

| 工具               | Arch 安装                      | 输出                                | 无头渲染                                                           | 要点                                                                                                                                |
| ------------------ | ------------------------------ | ----------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| d2 0.9.0           | `pacman -S d2`（extra）        | svg（png/pdf 经内置 chromium 下载） | svg 可以                                                           | 现代布局（dagre/ELK；TALA 收费）。约 20MB 单二进制；实测渲染 38ms，中文标签保留为真实 `<text>` 元素，`--font-*` 可指定嵌入字体[^d2] |
| mermaid-cli (mmdc) | npm `@mermaid-js/mermaid-cli`  | svg/png/pdf                         | 不行，需 puppeteer+chromium（约 150MB 下载或指定系统 chrome 路径） | 仅在 mermaid 语法本身必需时值得装；全工具链里最重路径[^mmdc]                                                                        |
| graphviz 16.1      | `pacman -S graphviz`           | svg/png/pdf                         | 零依赖可以                                                         | 老牌稳定，布局偏丑；中文经 `fontname` 指定字体可用                                                                                  |

| excalidraw         | 无头需 playwright+ 浏览器      | png/svg                             | 费劲                                                               | 手绘风；`ddarmon/excalidraw-tools` 是面向 LLM agent 的 uv 可装 CLI[^excal-tools]                                                    |

## 选型建议

若要一个「落盘即用」的现成方案：`Agents365-ai/365-skills` 的 mermaid 插件是唯一带「渲染 + 视觉自检回环」的完整流水线，且明示支持 `.agents/skills/` 路径约定，可以直接拷目录或 `npx skills add`；但它绑 mermaid 语法，渲染走 `mmdc`（chromium 依赖）或 Kroki（图源出站）。

若按 TeXlate 仓工具现状自造一个轻 skill，推荐分工：默认 d2（单二进制、真无头、布局最现代、中文实测正常），graphviz 兜底，目标是 GitHub/网页内嵌时直接产 mermaid 代码块（零渲染依赖），LaTeX 正文内嵌图用 TikZ。WH-2099 的逐型语法参考库值得作为参考资料直接引用或抄进 skill 的 references/。
