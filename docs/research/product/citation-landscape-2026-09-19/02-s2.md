# Lane 02：Semantic Scholar

> **结论**：S2 是唯一把「2.4B 条带属性引用边 + 120M 条 SPECTER embedding」做成可直接下载数据集的开放源；但匿名 API 是全局共享池、实测 429 命中率 >80%，不可做生产依赖。
> **状态**：时点证据（2026-09-19 口径）
> **日期**：2026-09-19

## 该源是什么

Allen Institute for AI 运营的学术图谱，三层服务：Graph API（实时图查询）、Recommendations API（embedding 推荐）、Datasets API（周更快照批量下载）。官方宣称 214M papers / 2.49B citations / 79M authors[^s2api]；datasets 快照（release 2026-09-17）为 papers 200M / citations 2.4B / authors 75M，量级一致。

## 数据面

**Graph API**（`api.semanticscholar.org/graph/v1`，swagger spec 公开可读）：paper/references/citations/authors/search/bulk/match/autocomplete 全套端点；paper_id 支持 S2 sha、CorpusId、DOI、ARXIV、MAG、ACL、PMID、PMCID、URL。实测要点：**老格式 arXiv ID（`ARXIV:hep-th/9901001`）正常解析**；新论文收录延迟 ≤10 天；**`GET /paper/{id}?fields=embedding.specter_v2` 直接返回 768 维 SPECTER2 向量**——单篇 embedding 免费通道实测可用；`POST /paper/batch` 在匿名池里始终 429 零穿透。

**边属性模型**（独一份）：每条边可带 `contexts[]`（施引论文正文提及该引用的原句）、`intents[]`（background/methodology/result 三分类，Cohan et al. NAACL 2019[^cohan19]）、`isInfluential`（Valenzuela et al. AAAI 2015 监督分类器，precision 65% @ recall 90%[^valenzuela15]）。两者都依赖施引论文全文可得性——实测 2026 年新引文 contexts/intents 全空，只有裸边[^s2faq]。

**Recommendations API**：仅 `forpaper/{id}` 与 POST 正负例两端点；`from=recent` 池只含近 ~3 个月新论文（对 2017 年老论文返回空），定位是「新论文追踪」而非「经典相关工作」。机制是 SPECTER 谱系 embedding 近邻——**引用图当监督信号训练 embedding，不是实时图遍历**：SPECTER2 的 triplet 中 P+ 取被 Q 引用或引用 Q 的论文[^specter2blog]。

**Datasets API**：`release/latest` 免 key（约每周一更；release 清单端点实测 197 个 release 中位间隔 7 天），数据下载与 `diffs` 增量需免费 API key；`ai2-s2ag` S3 桶有免费样本可直下做 schema 验证。关键数据集（release 2026-09-17）：**citations 2.4B 条 ≈255GB**（ODC-BY，schema `{citationid, citingcorpusid, citedcorpusid, isinfluential, contexts[], intents[]}`，`citedcorpusid` 可为 null 指向语料外）、papers 200M ≈45GB、**embeddings-specter_v1/v2 各 120M×768 维 ≈840GB（Apache 2.0）**、s2orc_v2 16M 全文结构化解析 ≈180GB、paper-ids 450M 映射（sha↔corpusId 桥）[^s2docs][^s2orc]。

## 可借鉴点

1. citations 数据集是地基级原料：属性维度独一份（OpenAlex 只有裸边），ODC-BY + diffs 增量；需一次免费 key 申请，corpusid 键经 paper-ids 桥到外部 ID。
2. embeddings-specter_v2 直接消灭「相似论文 embedding」子系统的训练成本：下载 + ANN 索引即得 S2 同款推荐底座；只取 arXiv 子集 ~3M 条 ~10GB 而非全量 840GB。
3. recent/all-cs 双池设计可抄：新论文追踪与全库相似是两种产品语义，分开服务。

## 结论

S2 的价值在 datasets 不在实时 API：边属性模型（contexts/intents/isInfluential）展示了「语句级边」的产品形态上限——texlate 的 LaTeX 源侧可自抽等效物且不受全文可得性限制，这是差异化空间。匿名 API 共享池实测不可依赖；若走「API 兜底长尾」混合路线必须申请 key（1 RPS 决定只能做 cache miss 兜底）。
