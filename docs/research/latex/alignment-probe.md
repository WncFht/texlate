# 双语滚动同步锚点探针 — named destinations 保留率验证

日期：2026-09-14。探针：`tmp/exp/align-probe/dest_probe.py`（pypdf 6.18.1，`uv run --with pypdf`），明细 JSON：`tmp/exp/align-probe/dest_probe_results.json`。

**问题**：同一 LaTeX 源编译出的 en.pdf（base）与 zh.pdf（ctex 注入 + 译文）是否共享 hyperref named destinations，足以支撑 texglot 式滚动同步？

**结论先行：方案成立，无需补丁即可覆盖 ~2/3 语料；剩余 ~1/3 无 hyperref 语料需兜底。**

- ctex 注入 + 全文翻译**不改变锚点名集合**：结构未被破坏的 10/11 对保留率 ≥0.94，其中 8 对 =1.000（含 778 页、5519 锚点的大书，全数保留）。
- 同名锚点位置漂移单调：section.* 结构锚点在 8/11 对中 100% 落入加权单调链，滚动同步骨架完整。
- 唯一严重掉锚案例（1502.01589，保留 0.65）根因是 **mock 管线把 7 行连续 `\input` 当一个 chunk 整体译掉**，正文没进 PDF——是分段器缺陷暴露，不是 hyperref/ctex 的锅。
- 退化路径实测占比 **5/16 ≈ 31%**（源文无 hyperref：0 锚点、0 outline、0 annots）。

## 关键发现

1. **名集合对 ctex+ 译文惰性**。所有存活锚点名逐字节一致（含 `cite.DBLP:journals/corr/BritzGLL17` 这类特殊字符名）。没有因 ctex/xeCJK 产生重命名或 fit 类型变化（两侧全 /XYZ）。
2. **掉锚机制 = 内容被吃掉，不是渲染问题**。1502.01589 中 `\input introduction … \input grid` 七行连续输入落入同一 chunk 被 mock 整段替换，正文 258 个锚点整批消失；`\input` 行前后各一行存活佐证边界在 chunk 内部。2609.09529 丢 12 个同理。→ **分段器须把 `\input`/`\include`/`\label` 列为 chunk 边界禁入区**（miniscanner 规则待加）。
3. **名 = 计数器值，重编号即改名**。2609.06443 zh 多出 Item.106–115（itemize 计数器因上游 chunk 丢失而漂移）；engine 对照组里 equation.1 vs equation.0.1、cite.* 有无，均由 aux/bib pass 差异造成。滚动同步建映射时按名配对天然容忍（改名=失配降级为插值），但也意味着**译文侧结构完整性直接决定锚点率**。
4. **页漂移大但形状健康**。mock 压缩下 Δp 中位 −3…−75；归一化阅读位置漂移 |d|med 1.6–8%，p90 ≤16%（健康对）。真实译文长度约为英文 0.6–0.8×，漂移方向相同、幅度更小。
5. **单调链掉的是局部抖动，不是骨架**。链权比 0.53–1.00；掉落集中在 cite._（参考文献段内部重排）与 float（figure/table 换位），section._ 在 8/11 对中 100% 入链。非严格单调完全可由 texglot 式分段插值吸收——保留链只是保守下界，每页仍有数个骨架锚点。
6. **对照组确认位置确定性**。engine 对同名锚点 Δp=0 占 95%+，同页 y 差均值 0.009 页高，链权比 ≈1.0：同名锚点位置由排版唯一决定，跨进程可复现。

## 退化路径（无 hyperref）占比 31%

5/16 工程 base PDF 零 named dests，且 **outline=0、Annots=0、/Names 缺省**（amsart 无 hyperref 老稿、revtex4 原版、LaTeX2.09、IEEEtran-latin5）。texglot 方案对它们无锚可用。因 en.pdf 也由我方编译，可选兜底：

- 对无 hyperref 源**双侧注入 hyperref**（老类风险：LaTeX2.09/ptptex 大概率挂，需逐类验证）；
- 退化为页号比例 + 文本锚点（取每页首行文本做 cross-lingual 匹配）；
- 或直接放弃滚动同步改双栏段对照。

## 对 roadmap 的建议

1. 滚动同步主链路按此方案实现：pypdf 抽两侧 named dests → 按名配对 → (page,y) 双增单调链 → 分段线性插值映射 scrollY。
2. miniscanner/分段器补规则：`\input`、`\include`、`\label`、`\bibitem` 行必须留在占位符侧，禁入可译 chunk（本探针的掉锚案例全是这条被违反）。
3. 锚点保留率可复用为 zh 编译完整性指标：<95% 时报警回查 chunk 丢失。
4. 兜底策略需立项：~1/3 arXiv 老稿无 hyperref，建议 v0 先「无锚点则提示不支持同步」而不是硬上文本匹配。
