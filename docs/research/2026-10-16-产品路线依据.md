# 产品路线与外部实现依据

本文提炼 2026-09 至 10 月的产品研究，保留影响 TeXlate 的机制与未采用方案。外部服务状态、价格和接口没有在合并日重新核验；它们不是当前互操作承诺。

## 产品边界

TeXlate 的主路径为 LaTeX 源码翻译后中文重编译，HTML 和 PDF 路径明确降级。HJFY 的产品观察支持源码保真、中文编译修复和对照阅读的组合；原站 API 不作为 TeXlate 内部架构模板。

PDF 页面保留与 OCR 到 Markdown 重排承担不同任务。BabelDOC 的独立引擎接入支持 PDF 译后产物；电子书插译采用保容器的段落处理，不把论文重编译链强套到 EPUB/DOCX。

## 实际采用的机制

TeXGlot 的屏蔽视图、源码归一化、命名锚同步、缓存语义和便携引擎分发为设计参考；借鉴模式不等于复制其实现。LaTeXTrans 与其他译稿工具的 prompt、术语与容器处理同样须经本仓保真与失败实验验证。

引用交互研究支持同锚 hover/click 分工、显式返回栈、本地条目优先与服务端元数据代理。引用图谱全量建库、embedding 推荐和复杂发现算子不是当前阅读器的必要前提；不因生态报告列出功能就将其转成产品承诺。

alphaXiv 公共发现面由服务端代理封装，上游返回结构和限流仍可能变化。papers.cool 与 Moonlight 的生成配额、增长、SEO 和公司信息不构成本项目当前契约，重复的生态产品矩阵和 agent 分工记录已退出正文。

## 暂未采用的路线

独立桌面壳、公共译文 registry、全量引用图谱与选区 AI 助手分别需要新的分发、许可、存储、配额或交互依据。历史否决只针对当时需求，不形成永久禁止；新提案需说明需求变化及重新验证条件。

HJFY macOS 0.1.5 的本地 BYOK 编排、独立引擎与渲染差分验证可作为研究候选。原报告中的逆向结果受该二进制版本限制，未证实的内部推断不能升级为已采用设计。

## 分发与许可

PyPI、容器、Release 和 Zotero 的操作以根 README、发布 workflow 和 `zotero/README.md` 为准。已提交登记、市场审核和远端可用是不同状态，不在旧调研中长期维护行动清单。依赖许可与 bundled 文件由 LICENSE、NOTICE 和实际分发产物核验。
