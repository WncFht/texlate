# 对齐与阅读器实验依据

本文合并 2026-09 的 PDF 保真、锚定、复制、引用与主题实验。交互现状见 [reader.md](../spec/reader.md)，对齐契约见 [reader-alignment.md](../spec/reader-alignment.md)。

## 原文 PDF 与自编译基线

官方 PDF 对自编译 PDF 的十五篇对拍中，仅一篇达到完全对齐口径，十三篇页数不同，页差中位数为四页。锚名还存在 equation 层级、平铺与纯数字等差异。因此不能把自编译命名锚直接套到官方 PDF，页数一致也不充分。

另一组原文自编译对中文编译的锚实验中，结构未破坏的十一对有十对锚保留率至少 0.94，其中八对为 1。同期约 31% 无 hyperref 需要降级。两个实验比较对象不同，不能混用成功比例。

## seq 标记与几何

marked-content 标记能给译后 PDF 提供 seq 身份，但宏回卷、移动参数、表格和运行页眉会改变字形覆盖。旧验证集十九任务在当时解码版本上 pick/page 指标全通过，后来扩展三任务真值后端到端误差指标下降；扩面改变分母，旧满分不能代表所有论文。

v25 三任务复测记录选中率双侧 100%，e2e@0.25 原侧 91.4%、译侧 97.3%。没有对侧真值的探针另报、不进该分母。页眉重复、数学字形、错栏与零字形标记需要分别处理；宁可报告无锚，不用邻段伪造成功。

## 源码复制与引用

公式载体实验中 MathML alttext 与 annotation 在 8,907 个公式上逐字节相同；这只覆盖该 HTML 样本。PDF 字形文本不提供同等公式源保证。句界外扩的源码切片在当时实验中平衡率为 99.6%–100%，中位多收 9–17 字符；不能把这种扩选称作精确字符选择。

引用条目既可来自占位符 bibitem，也可从 PDF 目的地或 HTML 文献节点抽取。浏览器 hover 直连公共元数据源会放大限流；本地先显示、服务端缓存增强支持降级阅读。PDFHistory 写浏览器 hash 会触发 SPA 路由，故使用独立导航栈。

收藏 sidecar 曾面临任务瘦身删除风险；数据库快照保存用户当时看到的条目，原 BibTeX 优先、快照合成兜底。相关测试应验证重试回边、跨 pane 导航、任务删除与瘦身后的内容，而不仅是按钮出现。

## 主题对照

四 PDF、每份六页的实验比较 CSS 反色、pdf.js pageColors 与图元改色。CSS 反色几乎无额外处理但损伤照片；pageColors 为双色调，难保彩色图表；图元路线按文字、彩色与图像分类，记录约 10–63ms/页，成本随页面图像回读变化。

实例级 getPage/render 包装避免维护 pdf.js fork。单色板轴解决纸面与界面分别控制产生的失配，none 提供原纸排障路径。旧截图、浏览器 harness 与历史通过数不自动证明当前依赖版本行为，需重新运行 `web/` 所属测试和真实渲染验证。
