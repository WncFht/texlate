# 抽样 frame 与簇/配额分配（corpus_v3 A3 回填）

> **结论**：以 `librarian-bots/arxiv-metadata-snapshot`（CC0）建成 3,164,528 行 × 14 列的分层 frame，新式 id 覆盖 99.9994%、旧式序号实测连续——快照可作无偏 frame；30 月簇（IA 24 + TIGER 6）按带内累计论文量等分位取月，核心 1,000 = 每带 200 × 5 带，配额、坑清单、可发布子集预测全部落定并执行。
> **状态**：已完成（frame 已建成并驱动 2026-09-15/16 实际抽样；分层计数与簇清单为 2026-09-14 快照口径）。现行语料层口径见 `bench/corpus/MANIFEST.md`。
> **日期**：2026-09-14

数据源：HF `librarian-bots/arxiv-metadata-snapshot`（CC0，lastModified 2026-09-14，10 shards）。约束遵守：全程只触 huggingface.co / archive.org（IA 尺寸校准），未请求 arxiv.org / AWS S3。

## 1. frame 构建方法

duckdb + httpfs 列裁剪远程扫全量 10 shards ≈122s（经本地代理），未落全量；只取 6/14 列（abstract/authors/title 等 8 列弃取不传输）：

```sql
SELECT id,
  CASE WHEN strpos(id,'/')>0 THEN 'old' ELSE 'new' END id_style,
  strptime(versions[1].created,'%a, %d %b %Y %H:%M:%S GMT') v1_ts,
  len(versions) n_versions,
  split_part(categories,' ',1) primary_cat,
  categories, license license_uri, ("journal-ref" IS NOT NULL) has_journal_ref,
  update_date
FROM read_parquet([10 个 shard URL])
```

派生列（`frame.parquet` schema）：

| 列                       | 定义                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| `first_version_yymm`     | `strftime(v1_ts,'%y%m')` — v1 提交月                                                                                |
| `id_yymm` / `tar_yymm`   | **id 内嵌月**（新式 `^(yymm)\.` / 旧式 `/yymmNNN`）= 月度 tar 成员归属月，簇抽样主键；缺失回退 v1 月（实测 0 缺失） |
| `tar_year` / `year_band` | tar_yymm → 日历年；带：`a_pre2007 / b_2007_11 / c_2012_16 / d_2017_20 / e_2021_25 / f_2026plus`                     |
| `primary_cat`            | categories 首 token（157 个 distinct）                                                                              |
| `cat_group`              | 8 组（映射实测全覆盖，`other` 组为 0 行）                                                                           |
| `license_class`          | `cc0-pd / cc-by / cc-by-sa / cc-by-nc-sa / cc-by-nc-nd / arxiv-nonexclusive / missing`（9 URI + NULL 全落 7 类）    |

cat_group 映射（对计划的微调：旧 archive 名归并——`alg-geom/dg-ga/funct-an/q-alg`→math；`cmp-lg`→cs；`mtrl-th/supr-con`→cond-mat；`chao-dyn/solv-int/adap-org/comp-gas/patt-sol/nlin.*`→hep-phys；`bayes-an`→eess-stat-etc；`chem-ph/atom-ph/acc-phys/plasm-ph/ao-sci/physics.*`→hep-phys）：

## 2. 覆盖率验证

- **新式 id（2007-04 起）**：逐月 `count vs max(seq)`——合计缺口 17 个 id（最大单月缺口 4），覆盖 2,750,324/2,750,341 = **99.9994%**，完备。
- **旧式 id（≤2007-03）**：逐 archive-month `count vs max(seq)`，抽样 arch-month（hep-th 9901/0006/0503、cond-mat 0403/0612、math 0701/0703）全部 `min=1, count=max` 连续；全表面「缺口」39,049 中 Σ(min−1)≈39,0xx——旧编号每月从 ~100 起排（hep-ph/math/cs/nlin），非缺失。真实空洞 <1%，旧式合计 414,204 篇。
- **规模锚点**：tar_yymm≤0612 = **400,888**（≈arXiv 2006 末存量 ~400k）；≤0810 = 384,796；≤2010（IA 截止）= **1,666,192**；≤2501（TIGER 截止）= **2,536,436**。逐年曲线平滑单调（1991:306 → 2006:50,239 → 2024:~28 万），无断崖缺块。
- **结论**：快照对 1991-07→2025-01 全时段可视作完备 frame；唯一系统缺口是 id 级删除/未公布（≤0.001%）与 pre-1991 backdate 杂项（§5）。

## 4. 簇选择与配额分配

### 4.1 方法

- 每带 **6 簇**（≥4 下限满足；30 簇 × ~33 = 1,000 与计划吻合）。
- 簇月 = 带内**累计论文量等分位点**（(i+0.5)/6, i=0..5）：自然按论文密度加权，又保证覆盖带首带尾。
- 抽样宇宙：a 带 **1995-01 起**（9107-9412 共 20,396 篇化石层有意排除，2.09 遗存由补强层在 ≤2000 簇挖）；d 带宇宙含 2011/2012（TIGER 有、IA 无的两月，分位点未选中）；e 带宇宙 **≤2501**（TIGER 截止；2502-2512 共 ~26.5 万篇不可达）。

### 4.3 核心层分配口径

**带内等分**（200/带 × 5 带），簇内再对 cat_group 做软配额。理由：等分给每带独立 Wilson/簇稳健 CI（带内零失败 → 1.5% 上界）；比例分配会让 a 带只剩 ~150 且 e 带 ~420，牺牲带间可比性。池化无偏估计用**事后分层权重**还原：w_cell = (frame 宇宙 cell 数）/（样本 cell 数），cell = year_band × cat_group。

## 5. 坑与字段异常实测记录

1. **`versions[1]` 恒为 v1**：3,164,528 行全量验证——empty=0、`versions[1].version='v1'`=100%、created 100% 可按 `%a, %d %b %Y %H:%M:%S GMT` strptime。文档坑未触发，但 frame 仍保留 raw created 供复核。
2. **id 月 ≠ v1 月**：新式 84,576 行（3.1%）、旧式 4,252 行（1.0%）。新式 +1 月占 77,650（月末提交滚入次月公布号段），+2..+21 月长尾（moderation hold）；旧式含 pre-1991 backfill 尾（v1.created 早于 id 月最多 98 个月，如 `math/9201203` created=1989-10）。**簇归属必须用 id 内嵌 yymm（tar_yymm），不能用 first_version_yymm**——月度 tar 按公布月打包。
3. **yymm 字符串比较在 2000 年界断裂**：'0612'<'9501'。所有区间判定必须先转年序键（yy<91→1900+ else 2000+）。
4. **shard 不按时序聚簇**：单 shard 内 v1 横跨 2009-2017（update_date 聚簇），任何年代统计必须全扫——httpfs 列裁剪 ~12s/shard 可接受，无需落地全量。
5. **license 是记录级最新版本值**（快照口径同 OAI）：a 带却有 3,693 nonexclusive + 190 CC——这些是 v2+ 版本补选许可的老论文，非字段错误。
6. **pre-1991 v1_ts**：34 行 created<1991-08（最早 1986-04），全为 backfill 旧稿；id 月才是打包月。
7. **2011/2012（2020-11/12）IA 无 chunk、TIGER 有**（86+94 个）：d 带宇宙含此两月，本方案分位点未选中；若要补 IA 末端空洞可用 TIGER。
8. **frame 不知道成员形态**（gz/pdf/空壳）：PDF-only 份额需成员扫描实测，配额按 ~5% 折损预留。
