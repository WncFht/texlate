# parsebench 月间簇 ICC(1) 分析 — corpus_v3

> **结论**：管线指标上月间簇效应 ≈ 0（log₁₀(tex_bytes) ICC 0.049 / chunks 0.009 / leak_rate −0.006 / n_tex 0.066，ok_rate 退化常数 1）——leak/chunks/ok_rate 的簇间方差均不显著，语料多样性在簇内。分层设计的目标本不是这些指标：簇对应年代带（docclass/宏生态随年代演化），保住的是**时代覆盖面**而非指标均匀性。
> **状态**：已完成（一次性分析，2026-09-15 执行；结论已沉淀为「逐篇 pooling 足够、时代效应按 year_band 分层报」的报告口径）。
> **日期**：2026-09-15

任务：月度簇分层抽样的簇间方差是否显著——决定后续抽样能否简化（对应 v3-plan §2 的 deff 论证缺口，文献中无 ρ 先验值，本分析用 corpus 数据自估）。

方法：one-way random effects ICC(1) = (MSB − MSW) / (MSB + (k̄−1)·MSW)，k̄ 为不等组调和校正；输入为逐篇 stats，分组键 `meta.cluster_id`（30 个月度簇）。

## 结果

核心层（n=1000，~33/簇）：

| 指标             | ICC(1) | 判读                               |
| ---------------- | ------ | ---------------------------------- |
| log₁₀(tex_bytes) | 0.049  | 体量有微弱簇效应                   |
| chunks           | 0.009  | ≈0                                 |
| leak_rate        | −0.006 | ≈0（簇间差 < 随机噪声）            |
| ok_rate          | 退化   | 常数 1（parse 100%，无方差可分解） |
| n_tex            | 0.066  | 多文件占比有微弱簇效应             |

补强层（n=187，~6/簇，机制策展非代表性抽样——ICC 仅作参考）：

| 指标             | ICC(1)                                |
| ---------------- | ------------------------------------- |
| log₁₀(tex_bytes) | −0.025                                |
| chunks           | −0.077                                |
| leak_rate        | −0.064                                |
| n_tex            | 0.256（策展偏好部分月份的多文件论文） |

## 结论与含义

- parse/compile 类 benchmark 报告簇间异质性无增益，逐篇 pooling 即足够。
- 若需时代效应，应直接按 `year_band` 分层报（meta.json 已带；manifest/meta 的 `stratum_cell` 前缀即 band），而非靠 ICC。
- 补强层 ICC 无代表性含义（机制抽样），上表仅完整起见。
