## C. 新运维经验

### C1. fleet/多会话协作（本会话视角，与 53215cda 互补）

1. **裸 `git commit` 席卷共享 index 事故（79ef694）**：把 1d 会话 staged 的 rules.yaml+489/builtins+238/两测试文件一起提走。虚惊结局：实现+规则+测试三件齐所以 HEAD 自洽不红——但从此纪律改为 **pathspec commit**（`git add <新文件> && git commit -m ... -- <paths>`），且提交前 `git diff --cached --stat` 审 index。事故通报格式值得抄：「不追责，立规矩」+ `git show --stat` 自验损失面。
2. **跨会话文件窗口协议**：`engine.py` 这类热点文件用 SendMessage 做「窗口关闭通知」（"我的 sandbox 窗口已关闭（b260378），你的 probe 现在可以落——注意 HEAD 已含 _bwrap_* 区块 L413+"）——交出所有权时附 HEAD 状态摘要，接收方不用重新 diff。
3. **三方 scope 谈判**：开工前先 SendMessage 换归属表；撞车任务直接 `TaskUpdate status=deleted, subject=[已让出] ...` 留痕。委托也可跨会话（1d 把 F3 fold-in 委托给本会话 server-polish）。
4. **agent 撞车误报**：server-polish 把 `engine.py:474` IndentationError 半截态记到 probe 头上，实际是另一会话 llm_hook agent 的在飞编辑——**「谁改的」要先问 leader 再指控**，归属表比 git blame 快。
5. **idle_notification 会重复轰炸**：同一 agent 交付后连发 2–3 条内容重复的 idle 报告，leader 按 dedup 处理即可；正式 TaskCreate 指派晚到时 agent 会回「已交付」——先派活再补登记是常态。
6. **~8 人满编流水线**：交付→验收→commit→`TaskStop`→同坑位补新 agent（web-fix→web-parity2、live-smoke→dist-smoke、probe→probe-wire、shared-cache→share-wire）。后续任务（ctex-anchor）直接由 bench 发现的真 bug 触发派生。
7. **网关并发纪律**：swe-2-medium 全局 cap 4 跨会话共享 → 单 agent 自限 ≤2，收到 stagerun real-xlat 批广播时暂停。
8. subagent 写 `bench/results/**/report.md` 被 harness guard 拦 → 全文 SendMessage 给 leader 代落盘（与 53215cda 同款，两个会话独立踩到）。

### C2. 产品/管线技术发现

9. **网关 swe-2-medium 对 `temperature=0` 直接 502**（`stage=response_event`），≥0.01 正常——judge 类调用永远别发 0。
10. **双账本口径 bug**：`tasks.tokens` 列存翻译期字符估算、teardown 真账只写 `task_usage` 表 → UI 快照恒低估 4.3×。凡「估算列+真账表」双写结构都要检查终态回写。
11. **ctex 改 theorem 锚名**：`\newtheorem{lemma}[definition]` 共享计数器时 hyperref 锚用计数器名（`lemma.3.x`→`definition.3.x`）→ en/zh named-dest 对拍掉点。B7 唯一未达标对的根因，属真产品 bug。
12. **share 寻址细节**：`pipeline_ver` 天生含 `|`（`texlate-{ver}|{prompt_ver}`）→ 分隔符注入检查只能约束前六组分；信任模型核心=下载译文只跳 xlat，splice/validate/compile 全本地重跑，恶意包最坏浪费一次编译。
13. **OAI-PMH 端点实锤**：`oaipmh.arxiv.org/oai`（export URL 是 301 壳）；版本史+license 只有 `arXivRaw` prefix 有。
14. **DOMPurify 3.4 把 `semantics`/`annotation(-xml)` 列入 mathMlDisallowed**（mXSS 向量）——别用 ADD_TAGS 重开；KaTeX 产物在 sanitize 后生成不受影响。测试环境 happy-dom 太松（script 都不剥），换 jsdom 才反映真实行为。
15. **XeTeX aux/bib 8192B**：写缓冲按字节切块会劈断多字节 UTF-8 → `\newlabel` EOF；修法是截尾整形到行界而非转码重试。
16. **工具误报两则**：`file` 把 zh.pdf 报 "4 page(s)"（pdfinfo 实 19）——`file` 的 PDF 解析器不可信；revtex endnote 单遍编译 undefined citations 是已知现象非管线缺陷。
17. **bench 门盘点结论**（复用价值高）：B3-zh 实质已近达标（fixloop-zh-cbv3 175 篇 union pdf 86.3% vs 门 200/90%）；B4b 只差 LLM-judge 花费；Mode C 只需 e2e_mock_bench.py 加 ~10 行 `--corpus` flag。「改口径复跑」比「重修管线」便宜——B7 换 pipe-fix 产物进对子即从 0.9167→0.9918。
18. **Dockerfile 经验集**：`uv sync` 默认带 dev group（pytest 进镜像）；fonts-noto-cjk 无 fontconfig 仅装饰性噪音（tectonic 内置 fontconfig 兜底）；tectonic bundle 首编联网拉且缓存在 `$HOME/.cache/Tectonic`（不在 /data 卷，离线部署要预热）；追加 texlive 变体必须插在 `USER texlate` 之前；`web/dev/` 必须留在构建上下文（vite.config 顶层 import）。
19. **done-doc 死路模式**：`Promise.all` 里一个 404 先拒 → 另一个永不到 → 产物无下载入口。多请求落地页要拆 Promise 独立落地。
