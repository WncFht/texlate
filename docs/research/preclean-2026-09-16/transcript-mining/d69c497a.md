### A5. 占位符契约校验（踩坑版→正确版）

```python
# 错误版教训：sqlite3 管道输出用 '|' 分列，译文里含 | 会把 split('|',1) 打歪——
# 报了 39 个假 mismatch（src#0）。正确做法走 python sqlite3 API。[#279→#287 u:5e3aee03]
import re, sqlite3
ph = re.compile(r'\[\[[A-Z]+_\d+\]\]')
db = sqlite3.connect('/home/fanghaotian/.texlate/texlate.db')
rows = db.execute("SELECT seq, src_text, translation FROM chunks WHERE task_id=? AND status='ok'", (tid,)).fetchall()
ok = bad = 0; det = []
for seq, src, zh in rows:
    s, t = ph.findall(src or ''), ph.findall(zh or '')
    if sorted(s) == sorted(t): ok += 1
    else: bad += 1; det.append((seq, sorted(set(s)-set(t))[:4], sorted(set(t)-set(s))[:4]))
print(f'{ok} preserved / {bad} mismatch of {len(rows)}')
# 结果：185 preserved / 0 mismatch
```

## C. 新运维经验

1. **SSH `-L` 远端目标的三个坑**：目标写 `127.0.0.1` 会撞上 Mac VS Code `Code H` 进程（独占 IPv4 loopback 3003，TCP 建立但永不响应——症状是连接成功+读超时）；写 `[::1]` 命中真服务；最终用户定规是远端 dial tailscale IP `100.105.212.52:3003`。
2. **隧道死于 tailscaled 重启**（exit 144 连死两次）：长期驻留隧道要 `while true; do ssh ...; sleep 3; done` + `ServerAliveInterval=15 ServerAliveCountMax=3`。
3. **sqlite3 CLI 管道不能喂含 `|` 的文本做精确比对**——分列符冲突，用 python sqlite3 API。
4. **sed 注入含反斜杠的行会被 `a` 命令吞转义**——改 .tex 用 python。
5. **curl `-o /dev/null -w '%{http_code}'` + `ss -tlnp | grep port`** 是服务生死的最快探针；`tail -n` 后台任务 output 文件看死因。
6. **`validate_base_url` 安全边界**：texlate server 强制非 localhost 走 https，所以产品链必须用隧道把网关映射回 `127.0.0.1:3003`；脚本/curl 才直连 tailscale IP。候选改法（未动）：放行 tailscale CGNAT `100.64.0.0/10` 的 http（WireGuard 已加密）。
7. **gwcap 全局硬闸 4** 会改变规模估算：swe-2-medium real 翻译 ~56 篇/h（不是之前估的 12 并发），300 篇 ≈ 5-7h 隔夜跑。
8. **withdrawn 论文的 IA 源是 124B `withdraw.txt` stub**（`format: "stub"`），盘点缺口时先排除，勿当真缺口去补。
9. **bench 侧烧配额前要有 preflight**：`e2e_real_bench.preflight()` 是 0 网络的导入面检查——并行 agent mid-refactor 留下的半成品源码（导入正常、调用即 NameError）曾污染整批 skip。
10. **签名单元 get 的用法**：`session_transcript.py get` 吃 `#n` 渲染号/uuid 前缀/toolu id——用 `u:` 前缀最稳。
