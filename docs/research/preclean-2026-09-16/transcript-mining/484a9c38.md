### A1. git stash 事故无损取证与逐文件恢复（本会话最大单坑）

```bash
# stash@{0} 内含 tracked + untracked 两棵提交；^3 是 untracked 提交
git stash show --name-only stash@{0}                      # tracked 清单
git ls-tree -r "stash@{0}^3" --name-only                  # untracked 清单
git log -g refs/stash --oneline                           # stash reflog
git reflog -15 --date=iso; git fsck --lost-found          # 丢活排查

# 导出整份快照到 scratch（不动 stash、不动工作区）
mkdir -p tmp/stash-recovery/tracked tmp/stash-recovery/untracked
for f in $(git stash show --name-only stash@{0}); do
  mkdir -p "tmp/stash-recovery/tracked/$(dirname "$f")"
  git show "stash@{0}:$f" > "tmp/stash-recovery/tracked/$f"
done
git archive "stash@{0}^3" | tar -x -C tmp/stash-recovery/untracked/
```

恢复两式及区别：`git checkout stash@{0} -- <paths>` 就地取回但**会写索引**（本次事故中把 sec-server 暂存区三件卷进了队友的 commit）；`git show "stash@{0}:f" > f` 只写工作区。校验「增长中的文件是否同根」用前缀比较：`head -n 2899 new.json | cmp - stash-copy.json`。[#2001 u:780fce9a, #2005 u:03893b95, #2015 u:c0ccd9c7, #2137 u:9ef64876, #1993 u:ca15a1c0]

### A2. 单文件 hunk 级选择性暂存（非交互版 `git add -p`）

一个文件的 diff 想拆成两个逻辑 commit 时：

```bash
git diff src/texlate/server/worker.py > /tmp/worker.patch
python3 - <<'PY'
raw = open('/tmp/worker.patch').read()
lines = raw.split('\n')
hdr_end = next(i for i,l in enumerate(lines) if l.startswith('@@'))
header = lines[:hdr_end]
idx = [i for i,l in enumerate(lines) if l.startswith('@@')]
hunks = []
for n,i in enumerate(idx):
    end = idx[n+1] if n+1 < len(idx) else len(lines)
    hunks.append([l for l in lines[i:end] if l != ''])  # strip phantom empties
def emit(path, hs):
    with open(path,'w') as f:
        f.write('\n'.join(header) + '\n')
        for h in hs: f.write('\n'.join(h) + '\n')
emit('/tmp/worker_compile.patch', [hunks[1]])
emit('/tmp/worker_web.patch',    [hunks[0], hunks[2]])
PY
git apply --cached --check /tmp/worker_compile.patch && git apply --cached /tmp/worker_compile.patch
```

### A10. 临时 TCP 转发（tailnet 服务映射到 loopback）

30 行 asyncio relay，当时用途：让只认 127.0.0.1 的产品链吃到 tailscale 网关：

```python
# /tmp/tcp-relay.py — python3 tcp-relay.py <lport> <rhost> <rport>
import asyncio, sys
LISTEN = ("127.0.0.1", int(sys.argv[1])); TARGET = (sys.argv[2], int(sys.argv[3]))
async def pipe(r, w):
    try:
        while data := await r.read(65536): w.write(data); await w.drain()
    except (ConnectionError, asyncio.IncompleteReadError): pass
    finally: w.close()
async def handle(cr, cw):
    sr, sw = await asyncio.open_connection(*TARGET)
    await asyncio.gather(pipe(cr, sw), pipe(sr, cw))
async def main():
    srv = await asyncio.start_server(handle, *LISTEN); await srv.serve_forever()
asyncio.run(main())
```

1. **stash 并发事故全景**：某 agent 为调无关测试跑 `git stash -u` + `git stash pop`，pop 撞并发提交未 drop——全队在途 tracked 编辑被收走、untracked 靠 pop 恢复但 tracked 没回来。恢复定式：快照导出 scratch（A1）→ 各 agent `git show stash@{0}:f > f` 或 `checkout stash@{0} -- paths` 逐文件自救（**绝不整 pop**）→ 全员广播自查 → 禁令升级为「禁止一切 git 状态命令」。次生坑：`git checkout stash@{0} -- paths` **会写索引**，把别人暂存的 hunk 卷进自己下一次 commit。[#1993–#2137 区间, 事故广播 #2030-#2042]
2. **SendMessage 协议帧**：shutdown_request 必须发结构化对象 `{"type":"shutdown_request",...}`，塞进 `message=` 文本会被拒（"must not be a teammate protocol frame"）。[#2956/#2959]
3. **Agent 批量 spawn 有锁**：一次起 13 个有 3 个撞 spawn 锁失败——失败了按名重试即可。[#2872 附近]
4. **gwcap 的 tailscaled 反欺骗暗坑**：nftables REDIRECT 后回包 unNAT，src=tailscale IP 且 iif=lo，会被 tailscaled ts-input 规则丢弃——只能在 `ip filter INPUT` 顶部插 `iifname "lo" tcp sport 3003 accept` 跳板；代理自身上游连接用 `meta skuid` 豁免。见 `scripts/gwcap/install.sh` 注释。
5. **ruff --fix 会删出 bug**：F841 autofix 把 `except Exception as e` 的 `as e` 删掉，payload 里 repr 的对象变成了错对象——autofix 后必须人工复核 diff。[stagerun 交付回执]
6. **`triage metrics|all` 写 git 跟踪文件**：`bench/results/metrics.jsonl` 入库了，冒烟跑会污染——已加 `--no-global`；教训：全局趋势文件要么 gitignore 要么默认不写。[#6165 区间]
7. **tectonic 版本岔路**：0.15 裸 CLI 用 `--bundle`，0.17 `-X compile` 子命令要 `--web-bundle`；`-vv` 要放 `-X` 后 `compile` 前；bundle 不可达时静默卡——先 `curl -sI` 探活，再用 `XDG_CACHE_HOME` 隔离缓存复现。[sub:a6b77be0]
8. **e2e_real_bench 可中断续跑**：`_paper_done` resume + records.jsonl append + `load_records` 末行胜合并；SIGTERM 后同参重启即续。但**运行中改 bench 脚本本身**要小心——进程持有旧内存映像，下次 resume 会混用新代码逻辑。[#3041-#3061]
9. **同机多 Claude 会话协同**：本仓当时还有 texlate-96/texlate-62/项目体验方式 等 peer 会话；SendMessage 可直接跨会话送达（"queued there — a Cross-session delivery notice follows"）。事故/占用要广播给 peer 会话别动 git。[#2041/#2042/#3950]
10. **xelatex ~100 error 上限**：nonstopmode 不豁免；zh tex 错误洪水 → mid-document abort → 截断 pdf（下游所有锚点丢失，bibliography 总是最先死因为在文末）。保留率对子测不准时先查这个。[b7-attribution 回执]
11. **`while ps -p`/`pgrep -f`/`pkill -f` 三件套**管后台产物；后台任务输出文件在 `/tmp/claude-1000/-home-fanghaotian-src-texlate/<sid>/tasks/<id>.output`。[#2291 等]
12. **metrics.jsonl 去重**：按 `run_id` 末行胜重写即可（jsonl append 语义无原地改）。[sub:atriage]
13. **uv.lock churn**：几乎每个 commit 前 `git checkout uv.lock`（已知，但频率惊人——约 15 次/会话）。
14. **`head -n N file | cmp - other`** 前缀比较：验证「增长中的 append 文件」与快照同源未分叉。

## D. 建议产品化

1. **`scripts/git-stash-export.sh`** — A1 整套 stash 取证导出（tracked+untracked^3 → 目录 + 清单 + 前缀校验）。理由：本次事故全手工，下次直接跑脚本。

   ```bash
   #!/bin/sh
   # stash-export.sh [stash@{0}] [outdir] — 无损导出 stash 两棵树
   set -eu; S=${1:-stash@{0}}; O=${2:-tmp/stash-export-$(date +%H%M)}
   mkdir -p "$O/tracked" "$O/untracked"
   for f in $(git stash show --name-only "$S"); do
     mkdir -p "$O/tracked/$(dirname "$f")"; git show "$S:$f" > "$O/tracked/$f"
   done
   git archive "$S^3" 2>/dev/null | tar -x -C "$O/untracked/" || true
   { git stash show --name-only "$S"; echo ---; git ls-tree -r "$S^3" --name-only; } > "$O/MANIFEST.txt"
   find "$O" -type f | wc -l
   ```

2. **`bench/py/` 探针骨架模板**（`bench/py/scratch/_template.py`）——本会话 200+ 次 `timeout N uv run python - <<EOF` + `sys.path.insert(0,'src')` 手写样板：

   sys.path.insert(0, "src")                            # 吃工作区码（TEXLATE_SRC 优先）
   import os; sys.path.insert(0, os.environ.get("TEXLATE_SRC", "src"))
