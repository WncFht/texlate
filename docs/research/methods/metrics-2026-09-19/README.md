`data/` 保存时间线 CSV、377 行评测流水、提交元数据和[里程碑来源](data/milestones.md)；`refs/` 保存两张历史图，未包含原报告所说的全部规范快照。`bench-pipeline.html` 是图源，`make_readme_figs.py` 是独立配图脚本，运行前核对字体与输出目录。报告中的旧运行目录不保证仍可访问，完整编译工作区和中间 PDF 没有入库。

在本目录运行 `latexmk -xelatex report.tex` 可构建报告，需 ctex、pgfplots 和 TikZ；报告图表使用包内数据，不依赖旧评测工作区。文档重构保留数据与既有 PDF，未重新运行原评测或构建此 PDF。
