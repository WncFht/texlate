## VLM 回复

已审图。以下按 checklist 逐条判定。

## 评审：arms-v5-validation.png（图3）

**1. 主张—数据一致性 — PASS**
- Σ 主张有证：标注框 "Σ 推算 1.53M → 实测 1.29M（84%）"，10 组柱目测合计与之相符（推算 ≈1.5M、实测 ≈1.2M）。
- "整体偏保守" 有证：7/10 篇 hatch（推算）> 实心（实测）。
- 反超篇断言精确命中：20739、19990、20581 三组恰为实心 > hatch，与标注框列名一一对应，无漏报无多报；其余各篇方向一致，无未解释的反转。
- 最高柱 19506（~650k/450k）与台账图2 焦点篇一致，不算未解释异常。
- 截断声明 "arXiv 2609.xxxxx" 在轴标题声明一次，不会误读。

**2. 标签可读性 — PASS**
- 标题、标注框三行、图例、x 刻度（45° 旋转必要）、y 轴竖排 "新输入 token / 篇" 均可读，无裁切无豆腐块；底部灰字标识行对比度在交付尺寸下可辨。

**3. 编码通道可辨识 — PASS**
- 单 teal 色相族 + hatch/实心双纹理区分推算/实测，同族同义（皆为 v5 量），纹理与类别单调对应；活跃色相 1 族 + 中性灰，远在预算内，色盲安全。

**4. 阅读顺序 — PASS**
- 标题→左上主张框→柱组→底部口径行，动线顺论证；x 序非数值非升幂（疑为处理序/与图1 对齐），未声明但不误导。

**5. 未埋点碰撞 — PASS**
- 标注框位于左上空白区，底边高于最高柱（19506 ~650k 未及 10⁶ 区）；图例右上无压柱；画布边缘无半裁元素。

**6. 图—caption 一致性 — CONCERN**
- 底部标识行写 "推算 = v4 观测 miss 谱 × S_v5 常数"，字面是乘法；台账主张的模型是 "Σuser 载荷 + miss 次数 × S_v5"（加法两项）。caption 丢了载荷项、把加法写成乘法——标注框 "批载荷 < 推算上限" 虽暗示载荷存在，但单行公式与台账口径不互证。属措辞级偏差，非主张冲突。
- 另：三篇反超柱仅靠 ID 对名定位，柱/刻度上无视觉标记（星号或描边），读者需自行搜寻。

## 总判：CONCERN

主张与图面证据完全互洽（反超三篇精确命中、84% 可核），可读性与编码皆稳；唯底部公式行把加法模型写成乘法，与台账口径不互证。

**最优先修改**：将标识行公式改为与台账同形的 "推算 = Σuser 载荷 + n_miss × S_v5（v4 miss 谱）"，顺带在 20739/19990/20581 三个刻度上加星号承接标注框。
