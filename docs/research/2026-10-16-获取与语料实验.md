# 获取渠道与语料抽样实验

本文合并 2026-09-14 至 09-22 的获取、渠道与语料实验。外部端点、覆盖和许可统计均为测量时点证据，未在 2026-10-16 重新请求上游。当前行为见 [arxiv-source.md](../spec/arxiv-source.md) 与 [corpus.md](../spec/corpus.md)。

## 获取与完整性

历史探针以 HEAD、条件请求、魔数和真实解包互证：`/src/{id}` 的 content-disposition 可预判 tar.gz、单文件 gzip 与 PDF；304 可用于缓存；旧 archive 大小写和 class 前缀会重定向归一。HTML latest 可能是 includepdf stub，不能以 HTTP 200 认定存在可译正文。

export 的 API 限流与内容路径表现不同，OAI-PMH 使用独立主机。一次探针无 429 不能推导永久免费吞吐；失败应保留日期、请求类别和退避条件，不能把某次连接失败当作资源不存在。Atom、OAI 与页面许可字段的差异要求元数据降级显式处理。

2026-09 的渠道比较区分完整源码、纯文本与元数据：IA 镜像、TIGER 与 scholarweave 的时间和二进制覆盖不同。TIGER 与 IA 的同月 tar 对照中 165 个成员有 123 个 sha256 相同，其余 42 个差异归因上游修订；这只证明该对照样本，不能外推全部文件版本相同。scholarweave 与 TIGER 同 id 的 140 篇对照显示大量文件和二进制缺失，因此有损渠道不得作为保图编译的等价源。

IA tar 成员 Range 抽取与本地解包曾逐字节对拍；48 篇抽样得到 79/79 文件解析成功且 identity 全同。后续换渠道、重压 tar 或变版本须重新验证 offset 与成员摘要。

## 抽样设计与资产

2026-09-14 元数据快照为 3,164,528 行。frame 使用 id 内嵌月定位 tar 成员归属，不能用 v1 提交月替代：新式记录中 84,576 行约 3.1% 存在月差，旧式有 backdate 和补版本。新式逐月序号覆盖为 2,750,324/2,750,341；这是编号连续性证据，不证明所有论文均有可编译源。

核心设计为五年代带各 200 篇，每带六个月簇，再按学科软配额。簇月依带内累计论文量等分位选择。带间等分支持年代比较；总体估计需按 frame cell 与样本 cell 数事后加权。补强、失败挖掘、hot 和有损近期层属于定向样本，不直接进入概率池化。留出层不参与开发调参。

月间簇效应实验中 log(tex_bytes) ICC 为 0.049、chunks 为 0.009、leak_rate 为 −0.006、n_tex 为 0.066；ok_rate 为常数而无法作有意义的方差分析。小 ICC 不消除年代覆盖需求，簇设计也不应只按这些代理指标判断。

抽样和来源的轻量资产保留在 `bench/frame/`、`bench/corpus/manifest*.jsonl`、`mechanisms.jsonl` 与 `eval_coverage.json`。现行层成员和校验摘要由 `bench/corpus/MANIFEST.md` 说明，不在本文维护第二份逐层数量表。

## 许可与分发

获取成功不等于获得译文再分发许可。历史许可分布和服务条款观察只能支持当时的来源评估；公开共享前须核对论文实际许可与当前适用条件。译文交换不默认授权建设公共托管库。上游复用说明见 arXiv 官方页面。[^reuse]

## 旧实验的适用范围

arxiv-to-prompt 的主文件定位、裸 input 和 verbatim 注释实验用于说明正则路径的反例；其当时版本和缺陷不能当今天上游状态。产品的未知命令保护与主文件定位仍以当前代码和回归测试为准。

日更 soak 方案已退役，不保留其部署排期。近期源可用性、批量成本和历史失败样本仍可指导新实验，但需要重新测量外部供给，不沿用旧促销或下载预算。
