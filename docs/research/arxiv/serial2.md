# arXiv 串行探针第二波：v-diff 增量重翻 / 官方 PDF 落盘 / 190 发大样本加厚

日期：2026-09-14 · 依据：本机串行探针 **258 发**（`tmp/exp/arxiv-serial2/requests.jsonl` 逐发记录），间隔 ≥3.1s、零并发、全程零 429；触顶预算 258 停发（尾部 8 个 2025-10~2026 样本未跑）。脚本 `tmp/exp/arxiv-serial2/probe2.py`（断点续跑），分析 `vdiff_analyze.py` + `sample_stats.py`。前作：`arxiv-probes.md`、`arxiv-layer.md`、`bench/results/arxiv-coverage.md`。

## 0. 结论速览

1. **增量重翻可省 ~50–85%**：8 对 v1→latest 实测，新版 .tex 行 verbatim 复用率（move-tolerant）**中位 0.52 / 均值 0.59**；同名文件对齐口径中位 0.87 / 均值 0.73。跨度越大、会议改版（换模板/换 bib 方案）省得越少。
2. **版本表机制可用**：`HEAD /src/{id}v{n}` 逐版本探测，404 定边界；裸 id GET 的 content-disposition 给 resolved latest。10 个知名 id 中 8 个有 v≥2。
3. **第四态再实证**：1412.6980 v9 e-print 仅 2 文件（`arxiv.tex` 壳 + `0_adam_main.pdf`），v1 19 文件全删——"latest 有源码"≠"latest 可翻"，复用旧版译文时也必须检查新版正文含量。
4. **官方 PDF 15/15 落盘**（`tmp/exp/pdf-fidelity/official/`），`/pdf/{id}` 直出 200 + `content-disposition: inline`（注意是 inline 不是 attachment），全部 ≤8.8MB。
5. **大样本（190 发）**：源码率——旧式命中 **52/53 = 98.1%**、新式命中 **92/97 = 94.8%**；**遗留尾巴零观测**（0/190 非 tar.gz/.gz/.pdf，rule-of-three <1.6%）——`.ps.gz/.doc/纯文本` 恐惧尾巴在本样本不存在。
6. **旧式 id 空间稀疏坑**：seq≤099 在低流量 archive-month 大量 404（nucl-ex 9/11、cs 8/10、hep-lat 6/9 等）；**旧 id 序号不按"当月第几篇"从 001 连续排布**——抽样/抓取器不能假设 seq 稠密。

### 1.2 v1→latest 逐对 diff（8 对，包已落 `vdiff/{id}/`）

指标口径（difflib 行级，对全部 text 文件）：

- `reuse_new`：同名文件对齐 equal 行 / 同名文件新版总行（不含新增文件——偏乐观）
- `tex_reuse_new`：全树 `.tex` 行多重集交集 / 新版全部 .tex 行（改名/搬动不罚，新增文件计为不复用——**最贴"省翻率"**）

| id         | 版本跨度 | 文件变化   | reuse_new | tex_reuse_new | 备注                                             |
| ---------- | -------- | ---------- | --------- | ------------- | ------------------------------------------------ |
| 1801.02634 | v1→v2    | +7 -0 ~1   | 0.9997    | **0.9985**    | 近乎纯增补                                       |
| 1706.03762 | v1→v7    | +14 -12 ~7 | 0.9084    | **0.8258**    | 6 版演进仍保留 83%                               |
| 2003.08934 | v1→v2    | +1 -0 ~10  | 0.8599    | **0.6102**    | 同名改 10 文件                                   |
| 2005.11401 | v1→v4    | +3 -1 ~11  | 0.8877    | **0.4555**    | v4 新增大段 tex                                  |
| 1810.04805 | v1→v2    | +24 -18 ~2 | 0.8652    | **0.4799**    | sections/→根目录大搬家，同名文件只剩 2 个改动    |
| 1403.3985  | v1→v3    | +3 -5 ~11  | 0.3247    | **0.5502**    | emulateapj→revtex 换类；`.bbl` 552→1793 行全换   |
| 2106.09685 | v1→v2    | +10 -6 ~2  | 0.2716    | **0.4612**    | NeurIPS→ICLR 模板整套换（sty/bbl/bst 全删）      |
| 1412.6980  | v1→v9    | +2 -19 ~0  | —         | (0.357)       | **边缘案**：v9=includepdf 壳，正文归零，不入统计 |

- **统计（7 对正常）**：tex_reuse_new 中位 **0.52**、均值 **0.59**；reuse_new（同名对齐）中位 0.87、均值 0.73。
- **结论——「出新版时译文缓存能复用多少」**：行级 verbatim 下界 **~50–60%（均值）/~52%（中位）**；若按段落哈希 + 模糊匹配（阈值 ~0.9 相似度即复用）可望推到 **60–85%**。**缓存键设计含义**：段落级缓存 + 按（id,old_ver→new_ver）存映射可省一半以上重翻成本；但要对「换模板/换 bib 工具链」（1403.3985、2106.09685 两例 ~45–55% 流失来自 preamble/bbl 整体替换）和「结构搬家」（1810.04805）鲁棒——**按内容指纹而非文件名配对口令必要**。
- **1412.6980 边缘案（不入统计）**：v9 e-print 合法 tar.gz 但删光 19 个正文文件只剩 `\includepdf` 壳 + PDF。即便走"旧版译文复用"路线，也必须先对新版做正文含量检查——否则复用对象不存在。
- `.bbl` 差异是噪声大户（1403.3985 的 1793 行全换是 bib 工具重生成）；翻译只消费 .tex，**bbl/sty 变化不应计入重翻量**（tex_reuse 口径已剔除）。

## 3. 任务 C：190 发大样本（`sample.jsonl`）

采样：旧式 12 archive × 3 YYMM(1996–2006) × 2 seq(001–099)，404 重抽一次；新式 2008–2017 ×6 + 2018–2026 ×5，月内均匀（上界=当月真实投稿数 `/tmp/arxiv_monthly.csv`），404 重抽一次。判定全部来自 HEAD content-disposition，未下载。

### 3.2 源码率（剔除 404，分母=命中）

| 池                     | 命中 | 有源码 | 源码率    | PDF-only 率 | 单文件率（源码中） |
| ---------------------- | ---- | ------ | --------- | ----------- | ------------------ |
| 旧式                   | 53   | 52     | **98.1%** | 1.9%        | 28.8%              |

- 与 60 篇基线（源码 86.7%、PDF-only 13.3%）同向；本波新式 PDF-only 5.2% 偏低但 CI 重叠。**旧式近全源码（98%）实证了"老论文几乎必有 TeX"**，且旧式 PDF-only 唯一一例是 cond-mat/9610071（直投 PDF）。
- **旧式单文件率 28.8% ≈ 新式 2 倍**（16.3%）——老论文更常单 tex 直投，解包路径必须保住单文件 .gz 分支。
- 新式分年：PDF-only 散在 2011/2012/2016/2017/2023（各 1），无明显年代聚集；2025 仅 2 发、2026 零发（预算触顶，见 §4）。

### 3.3 遗留尾巴：**零观测**

- 190 发 200 响应里 filename 后缀只有 `.tar.gz`（114）/`.gz`（30）/`.pdf`（6）三类——**`.ps.gz`/`.dvi`/`.doc`/纯文本/其他魔数 0 例**（含 1996–1999 最老样本）。rule-of-three：真实"其他"率 **<1.6%（95%）**。
- 含义：`gunzip→ustar 嗅探→%PDF` 三态判决对 ~98.4%+ 语料充分；"其他"桶按 §3.1 记 unknown 人工看即可，无需预建 dvi/ps 工具链。

### 3.4 旧式 id 稀疏坑（采样方法学副产物）

- 39/92 旧式请求 404——**seq≤099 并不稠密**：nucl-ex 9/11 404、cs 8/10、hep-lat 6/9、math/9710 与 cs/9603、cs/9709、hep-ph/9909 整月全灭（抽 4 发全 404）。
- 成因判读：低流量 archive-month 月投稿 <抽取序号（如 hep-lat ~50/月 → seq 060–099 多空）；1996–97 的 cs/math 月流量极小或走 subject-archive 命名空间（math.AG→math 归并仅覆盖部分时段）。
- **对抓取器含义**：旧式 id 空间 seq≤099 有效率 ≈58%（53/92）——批量枚举式抓取必须容忍大量 404 且**不能**用"seq 连续"做完整性假设；排序种子层靠引用图发现 id 而非枚举，正好规避此坑。
