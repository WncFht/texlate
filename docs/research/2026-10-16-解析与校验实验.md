# 解析与校验实验依据

本文保留 2026-09 的解析选型、展开时机和校验实验口径。结果对应当时实现，不是当前版本重新跑出的验收。当前契约见 [latex-pipeline.md](../spec/latex-pipeline.md)、[validate.md](../spec/validate.md)。

## 半解析与宏顺序

早期手挑语料为 39 篇、256 个 TeX 文件，包含结构宏、裸 input、非 UTF-8 和旧文档类。选型期间第三方解析成功不能证明内容识别正确；组内环境、注释和未知宏参数出现静默吞字。区间 pieces 与原始字节回写因此同时要求解析可用性与 identity。

早期 spike 记录为 259/259 文件 identity 全同、32/32 陷阱通过、泄漏率约 0.11%。另一自然分布样本为 137 篇、223 文件，解析与 identity 全通过，泄漏为 15/17,375 chunks，约 0.086%。二者样本与文件分母不同，不能将泄漏率变化直接归因为实现改进。

展开时机实验使用 39 篇、44 主文档和 55 文档级单元，展平后扫描定义与首次调用。正文 use-before-def 为 0，正常序宏名 1,351，preamble 前置使用 12 名，首次使用后重定义 3 个事件。重定义说明“先收集最终宏表再展开”会改变早先调用的语义；正文零前置使用只是该样本的支持证据，遇新语料仍需诊断与保守回退。

宏体连续 prose 至少 20 字符的严格口径覆盖 9/39 篇，字母总数超过 20 的宽口径覆盖 21/39 篇。两者度量不同；短词加引用的宏不能因严格阈值而被当作纯结构。input/include/subfile 引用事件共 201，最深四层，注释中的 input 不得展开。条件宏与 `newif` 必须先按宏表分类，不能把所有 if 前缀控制序列当条件。

argspec 覆盖实验对约 30 万次命令调用得到出现次数覆盖 78.6%、环境 98.9%。未覆盖部分包含论文自定义宏与原语；覆盖率不等于可安全消费未知参数的比例。当前表由 `src/texlate/latex/data/argspec.json` 维护。

## 校验器正反例

L0 实验使用七篇主文档、每篇至多 25 个 chunk，并分别在占位符与 raw 层施加破坏，共 1,636 对。10 类破坏中的 1,323 反例全部检出，313 干净对 error 误报为 0；warn 中仍有低可译文本比例的数学密集块。耗时为当时环境约 0.57ms/对，不是跨平台保证。

破坏覆盖括号、数学定界、环境名、引用 key、占位符缺失/拼写和幻觉控制序列。原稿已有的轻微不平衡采用相对判定。占位符 lev≤2 的建议修复命中 135/138，其他情况仍报缺失与多余；自动建议不等于可无条件修复。

可选 tree-sitter 实验为 40/40 破坏检出，干净样本无误报；57 个真实文件中 42 个已有 grammar ERROR，约 73.7%。绝对 ERROR 计数不适合直接拒绝原稿，必须与源 baseline 比较。CST 提供节点定位，不能替代源译 key 多重集等跨语言比较。

raw 规则对 verbatim、注释与语法坏区有盲区，占位符保护和 CST 分别补充。校验器自身也曾因控制序列词法处理错误导致 key/env 检查失效，因此每个 checker 都需要可拒绝的反例。

## 后续大样本记录

重构前 README 另记录了后续规模：7,343 个 TeX 文件解析错误为 0、identity 为 100%，chunk 泄漏 70/703,498，约 0.010%；12,653 篇论文的破坏校验漏检 64/565,318，正常文本 error 误判 0.49%。这些汇总对应后续测具和语料，不能与上面的早期手挑集直接作改进幅度比较；原始逐格大载荷不在本报告内，文档归并没有重新执行这些评测。

## 可复核范围

陷阱字节与断言位于 `bench/fixtures/` 及 `tests/latex/`，评分机制位于 `bench/py/specs/parsebench/`、`validbench/` 和 `_fixture_matrix/`。复算应使用对应 manifest、seed 与源码版本，不用手挑集结果推断近期学科总体。

后续宏展开与拼接已多次变化，历史旧 scanner 的文件清单和迁移步骤不作为当前说明。有效的不变量和失败反例由当前规范及测试继续维护。
