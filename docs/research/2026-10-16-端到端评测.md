# 端到端、原文基线与版面评测

本文合并 2026-10-02 至 10-08 的冻帧评测。合并日期为 2026-10-16，没有重跑付费实验；各行仍保留原样本和时间口径。指标定义见 [benchmark.md](../spec/benchmark.md)。

## 实验设计

全链 stage 为 route、xlat、compile、fixloop、base、layoutqc。xlat 使用当时的 swe-2-medium 经内部 OpenAI 兼容网关调用；compile 与 base 使用 XeLaTeX，fixloop 执行本地规则修复。base 是原文直编而非同等修复后的上限，不能把两臂差值全解释成翻译收益。

任务清单保留在 `bench/nominations/e2e_eval_holdout.jsonl`、`e2e_eval_cs.jsonl` 与 `e2e_eval_cs800.jsonl`。汇总按每格最新非 dedup 执行还原；dedup 行不增加独立实验样本。同 id 在不同 variant/世代可能对应多格。

## 分帧结果

| 测量日期与帧      | 交付           | base 交付      | 解释                                         |
| ----------------- | -------------- | -------------- | -------------------------------------------- |
| 10-02 holdout-200 | 171/200，85.5% | 152/200，76.0% | 历史跨学科样本，2021 年后 CS 仅 14 篇        |
| 10-03 CS-200      | 191/200，95.5% | 192/200，96.0% | 新 CS 专项；上游死 8，编译修复后仍失败 1     |
| 10-04 CS-800      | 725/800，90.6% | 715/800，89.4% | 含供给失败与限流恢复补跑；不等同纯翻译准确率 |

CS-800 首波约十一小时限流，记录 91,758 次拒绝，144 格耗尽重试。恢复后两波补跑回收 133 个 xlat 格，补跑计费合计 25.84 美元。首波 74.3% 与补跑后 90.6% 属不同运行条件，报告保留二者，不能删掉服务退化成本。

CS-800 的 e_2021_25/cs 574 篇交付 94.6%；dev_recent/recent 111 篇为 70.3%；holdout/recent 106 篇为 89.6%。层间源供应和年代不同，不池化成“新 CS 固定成功率”。

## 版面与浮体回放

原运行质检按历史 stage 状态记账；修后离线复测另取 885 篇直出交付面，clean 641、warn 211、hard 33。fixloop 救回的 47 格不在该离线帧中，因此不能把 885 的分布代表全部 932 个交付格。

六篇浮体受害篇回放发现，仅放宽 fraction 没有覆盖缺少 `p` 浮体页权限的源码。对合法 figure/table spec 补 `p` 后，float_drift 合计 21→2，order_inversion 69→5，六篇均编译 rc=0，无新增 specifier-changed 告警。`[H]`、已有 p、空 spec、keyval 和非浮体不修改；残余超大浮体和跨栏个案仍存在。

这项修复发生在帧测之后，历史 ledger 未回灌，不把六篇改善追写为原样本的新交付率。质检定义与盲区见 [layoutqc.md](../spec/layoutqc.md)。

## 原文直编普查

10-02 的 5,000 篇原文直编记录为 clean 2,896、partial 1,067、fail 767、reject 270。fail 中 missing_file 708，其中 vendor 已备 645、未备 63。备件存在不代表该原文基线已经运行了修复；不能把 645 直接从 fail 改记为成功。

学科与年代高度相关：astro-ph 732 篇中 fail 293，CS 缺件率约 4.7%。这些数字支持区分绝版宏包长尾与近期 CS，不能用一帧得出的水平推断全部 arXiv。

## 证据与限制

轻量样本清单保留在仓库，逐格执行账、付费 splice 与回放结果按 `TEXLATE_BENCH_ROOT` 的 ledger/runs/vault 分区管理。当前仓库不携带完整现场，因此本文数值是合并的历史记录，不能承诺 fresh clone 能独立重算全部历史格。

后续复测须保存版本、引擎、源快照、模型、并发、恢复次数与支出，并分别报告供应、翻译、编译和版面失败。质量 judge 与交付率是不同轴，方法见 [评测方法](2026-10-16-评测方法.md)。
