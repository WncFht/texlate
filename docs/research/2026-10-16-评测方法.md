# 评测方法与解释边界

本文提炼原语料构建、解析度量、翻译质量、自改进与版面损伤研究。实现与运行入口分别见 [benchmark.md](../spec/benchmark.md) 和 [bench 手册](../dev/bench.md)。

## 样本与区间

概率核心样本支持总体估计，定向故障样本支持机制覆盖。按年代等分抽样需事后分层权重才能估计总体，跨月簇应保留簇结构。核心、hot、booster 和失败挖掘层不能不加说明混成一个成功率。

二项指标使用 Wilson 区间；零事件可用 rule-of-three 作近似上界，条件为独立同分布近似且样本足以支撑该解释。零失败不证明真实风险为零。若希望对发生率 p 的故障看到约三个实例，n≈3/p 只是规模启发式，不能替代检出概率或功效分析。

## 结构、交付与质量

解析报告区分可读取、可解析、identity、可译覆盖与泄漏；按文件、论文和 chunk 的分母分开。编译成功只证明相应引擎路径出件，文本完整性和版面缺陷另测。

译文质量采用有具体错误标注的 judge 协议，不只取一个总分。ESA/MQM 类方法分别组织错误跨度、严重度与整体判断；用于本项目时需固定 rubric、模型、版本和解析协议。质量分不能替代占位符多重集、引用和公式结构的确定性校验。[^gemba]

LLM judge 存在自偏好、位置和长度影响；同源翻译与同源 judge 的分数不视为独立证据。配对比较保留同篇关联，跨文档汇总采用对应 block bootstrap 或簇处理；显著差异不能只用多个 chunk 当相互独立样本放大。[^self]

## 占位符与上下文负结果

2026-09-29 的 values 实验比较截断、全量、删除与段内重复上下文。记录的 XCOMET-QE 配对差异为：全量 −0.0041±0.0057、无 values −0.0032±0.0060、keep 加 values −0.0011±0.0049（各臂约 300 unit，95%CI，基准为 2k 截断）。区间包含零，只能表述为该实验未检出差异，不能宣称质量代价严格为零。

段内重复 values 的字符开销约为裸载荷 +100%，全量合并尾块约 +88%，keep-only 约 +23%。高温应力仍出现 NBSP 丢失与解析失败；keep 名单不构成绝对可靠性保证。重试数量既受成员难度影响，也受当时上游窗口影响，需健康上游重放来区分。

## 缺陷回放

源/译、修前/修后、编译/质检各自建立基线。模型失败、协议失败和供应失败分开归因，禁止按首个可见症状直接添加规则。反馈回路保留假设、可证伪条件、真实正例与近似反例；不以持续增加语料和修复次数代替验证。

版面代理应报告空页、overlap、overflow、浮体和内容退化的适用边界。相对基线可以减少源稿本身缺陷的误报；公式渲染等价和表格 cell 结构仍需要更强证据，不因 PDF 可抽文本就声称已验证。
