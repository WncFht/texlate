### 口径判读（spec 原意 vs 可选读法）

docs/10 §8 B4b 门槛原文："100 篇真实翻译端到端 ≥85%；硬契约率大样本不回退（对照 80/80 基线）；L0 检出率不回退"。B4b 是**翻译质量层**，编译进网格是"测翻译对编译的实际影响"而非门槛本身（编译 ≥90% 是 M2 自己的出口门；n100 里 base-xel 英文原文 clean 仅 10/71≈14%，85% 编译口径在 M1 不可能成立）。

- **chunk 终态**：ok 10715/10718 = 99.97%（partial 3、fault/skipped 0）——粒度过细，只作支撑。
- **篇级翻译端到端**（全 chunk 有终态译文 ∧ splice 残留=0）：partial 是阶梯后段"recovered"——译文仍交付。as-run 残留受损 7 篇 → 根因修复后复验归零。
    - as-run 严口径（全 ok ∧ 无残留）：82/91=90.1% 执行篇；含 reject 分母 82/100=82%（临界）。
    - post-fix（残留已修）：89/91=**97.8%** 执行篇 / 89/100=**89%** 抽样——两种分母均 ≥85%。
- **含编译 clean 读法**：pipe-xel clean 28/91=30.8%——如上判为非 spec 原意（与 M2 门 + base 14% 矛盾）。

### 保留项

1. n100 证据跑在 **v1 扫描面**（快照 4e06299 早于 S3/cutover）；v2 产品面真实翻译验证目前只有 n=10——v2 的 n100 复跑是收尾缺口。
2. 硬契约率对照：xlatbench-contract-2026-09-15 实测 swe-2-medium **79/80（99%）** vs E22 基线 80/80——新增 1 例 `\`+中文熔合失败（1207.7214#0，报告自评"E22 的 100% 是样本运气"）；swe-2-high 80/80。严格读 = 基线边缘回退（单样本），建议门判定按"n100 默认模型实测 99% + 高位模型 100%"留档。
3. 9 篇 reject 为正确产品行为（latex209 探针实证 + 无 main tex），不是翻译失败；若验收方坚持计入分母，post-fix 口径 89% 仍过门。
4. 管线引入编译回归（pipe 非 clean ∧ base clean）：n100 8 篇、post-cutover n10 2 篇——M2 相关信号，不计入 M1 翻译门但需结转。
