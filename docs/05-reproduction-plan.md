# 复现方案与实施计划（docs/05）

> 目标：复现 `docs/original.md` 描述的 hjfy.top 系统 —— arXiv LaTeX 源码 → LLM 段落级翻译 → ctex 重编译 → 双语对照阅读。
> 本文是 ~20 项子调研/实验（产物在 `docs/research/`、`tmp/exp/`、`tmp/refs/`）的综合裁决：每一项 pending 决策给出结论 + 证据出处。
> 状态：调研完成，方案冻结，可按里程碑开工。

## 0. TL;DR

**可行性结论：路线已验证到"机械链路全通"的程度。** 解析（miniscanner 259/259 + 0.11% 泄漏）、拼接回写（identity 100%）、校验（规则层 10 类破坏 100% 检出 / 0 error-FP / 0.57ms）、编译修复（fixloop 16/16 救回）、ctex 注入（xelatex 与 tectonic 双引擎实测可编译）五个最难的环全部有实证。E2E mock 实验（注入 ctex + 占位译文 + 拼接 + 编译）在 **16 篇语料上 16/16 出 PDF、0 FAIL；13 clean + 3 pdf~（全部由原文预存在错误主导）、splice 111 文件字节级 identity+ 零残留占位符**——机械链路无一致命断点。实验还抓出两个必须前置处理的问题：**miniscanner `_args` 吃 `\` 语科级 bug**（全语料 3452 处切断、1053 在可译 chunk 内、identity 检查盲——已补丁修复 0 残留，上游化清单见 §5.2）；**LaTeX 2.09 文档注入 `\usepackage{ctex}` 是最坏静默失败**（ctex 不加载、PDF 照出但 5954 Missing character、0 中文字节——必须前置路由 reject + verdict 加"中文实际渲染"检查）。

**与 hjfy 的差距不在架构而在规则库厚度**：hjfy 的 5% 残余错误率是 ~5000 文件人肉修复沉淀出来的。我们的等价物 = yaml 规则库 + cases.jsonl 沉淀机制 + LLM 修复器兜底，机制已设计完、首批 16 条规则已实证。

**新增关键设计（本轮调研的增量）**：texglot 的"源码归一化层"（pdfTeX→XeTeX 手术包）、named-destinations 滚动同步、段级缓存键、BYOK 抽象、编译沙箱、tectonic 分发矩阵——六块直接照抄设计，见 §5。

**LLM 后端已打通**（E21，2026-09-14）：本机 `127.0.0.1:3003` 网关（devin-2ap 上游）实测可用——**占位符契约 12/12 全绿**（3 模型 × 4 样例，0 丢失 0 幻觉），推荐 `claude-sonnet-5-medium`（3s/chunk、token 最省；**E22 大样本横评后默认改判 `swe-2-medium` 免费档，sonnet 转付费对照——见 §3 裁决 11**）。剩余未验证项收敛为：大规模回归、整篇真实翻译的编译影响、成本计价。

### 5.1 `texlate/arxiv/` —— 下载/元数据/缓存（规格：arxiv-layer.md）

- 端点分桶限速：`arxiv.org` 与 `export.arxiv.org` 各自 ≥3.05s 全局间隔、零并发；UA 强制 `texlate/{ver} (+repo; mailto:)`。
- 每个 GET 前先 `HEAD /src/{id}`：content-disposition 拿 resolved_version+ 格式、content-length 上限 150MB、etag 重验证。
- 退避：单请求 429→+10/30/90s jitter；**同 host 连续 2 次 429 → 队列 park 15min**（实测惩罚窗口 ≥3min，原地重试是浪费），翻倍上限 2h，checkpoint 落盘可恢复。
- 解包：魔数三态（`1f8b`→gunzip→ustar 嗅探 / `%PDF`→sidecar / 其他→人工）；bsdtar 不碰 gz-非-tar；逐成员路径安全（`..`/绝对路径/link/setuid 拒、大小写折叠冲突检测、≤512MB/≤20k 成员/≤100MB 单文件）；`mtree.txt`（path+sha256）每包一份。（勘误 2026-09-17：mtree 实为 TSV `path\tsize\tsha256\tkind[\t-> target][\tstub]` 多列；另增**别名落点对账**——经 kept symlink 祖先写穿的成员，mtree 先到条目以赢家实况记账 + `dup_member_overwrite` 告警；详见 docs/06 §2.2。）
- 主文件：剥注释匹配 `\documentclass|\documentstyle` → `\begin{document}` 优先 → include 图根 → 文件名先验 → 多根标 `multi_doc` → 零候选走降级。
- 元数据：Atom `id_list` 批量（≤200/次、URL ≤8KB 分批）；primary_category → 术语包映射；authors → 不可译名单；`resolved_version` 陈旧检测。

### 5.2 `texlate/latex/` —— 半解析器重写（规格：miniscanner-rewrite-spec.md）

9 文件布局：`tables.py`（19 行 dispatch + argspec.json 装载）、`model.py`（Piece/Chunk/ArgSpan/ArgSpec/MacroEntry dataclass）、`placeholder.py`、`macro_table.py`（六类 def）、`scanner.py`、`flatten.py`（Mouth 栈）、`reconstruct.py`（DAG memoized 展开）、`api.py`。
泄漏修复四机制：`_args(allow_single_token=False)`+math-debt 修复 / in-arg 注释→`[[COMMENT_n]]` / env `rstrip('*')` 归一 + 未知 env in_arg→`[[ENV]]` / in-arg 条件式→`[[COND_n]]`。
**分段器硬要求（E18 实证）**：`\input`/`\include`/`\label`/`\bibitem` 必须留占位符侧、绝不进可译 chunk——连续 `\input` 行被当单 chunk 吞掉会连锅端掉锚点与正文。
**回输修正（E5 实证）**：`flatten_inputs` 必须支持裸文件名 `\input file`（读 `[A-Za-z0-9._/-]+` 至空白/反斜杠）；`\if` 判定前置查宏表（`\ifb` 单位宏陷阱）+"非原语 `\if` 紧跟 `{` 即宏调用"（`\ifAnonymous{T}{F}`）；`\newif` 旗标名不入条件栈。
**E20 回填三缺口**：①`\subfile{}` 必须展开且 `\end{document}` 只在顶层截停——2609.06443 子文件自带 document 壳，不修时 335 chunks 被截成 7；②**巨型原子 chunk 需超阈值二次切分 / 宏参数内联上限**——`\version{}{…}`（`\ifbool` 二选一）把整附录内联成 109K 字符单 chunk、ATLAS 作者名单 77K 字符块，不切会爆单请求上下文；③零文本论文优雅跳过——1412.6980 是 `\includepdf` 包装纸，0 chunks 属正常走降级而非 bug。
**E10 补丁上游化（monkeypatch 已验证全语料 0 残留）**：①**BUG1 必修**——`_args` 单 token 参数不跨 `\`（3452 处切断、1053 在可译 chunk 内、identity 不可见，最恶性：`math/0404188/main.tex:111` `\begi|n{abstract}`）；②bare `\input` 文件名整段 literal；③DIM_BOUNDARY+ARG_BOUNDARY（`\vglue -10mm`/`\vspace`/`\setcounter` 等 ~40 命令）——**注意：chunk 内 literal piece 仍会被翻**，保护必须 `run.append(_ph(...))` 而非 flush_run 的 literal 形态；④DELIM_BOUNDARY（`\left(`/`\bigm|`/`\\[2mm]` 的 `* [dim] 定界 token`）；⑤回归断言"ph 尾 `\letters`+后继字母"=0（identity 检查对此类切断盲）。另：`cjk_glue_fix`（`\cmd这是`→插空格）是 post-reconstruct 一步全局修正，放 splice 层。
验收门：identity 259/259、泄漏 ≤5、traps 32/32、ph-边界切断 0。

### 5.3 展开层（规格：expansion-design.md）

- 三段移植：Mouth（字节→token 流，`\input` 中途压栈、makeatletter 可变 catcode——E5 实测 14 区 median ~150 字符，当普通边界命令即可）→ Gullet（宏表 + 不动点展开；`\def` 定界参编译器已备（plasTeX `__init__.py:1170-1235`），v1 可先当 opaque 降级）→ Segmenter（段落切分）。
- 资源限：gen≤32 / steps≤100k / inputs≤8 / dep≤4 实测余量充足。
- **铁律：splice 永远用调用点字节，gen>0 展开产物只进分类器**。
- `\if`：结构化配对不求值——`\iffalse` 丢块 / `\iftrue`·已知旗标留块 / `\ifmmode` 取数学支 / 未知旗标整段字面或取 else（E5：含 prose 块仅 5，4 个在 preamble）。
- transparent 判据：宏体去控制序列后 letters 总数 ≥12–20（E5：≥20 连续 prose run 严口径只覆盖 9/39，短词型 `Figure~\ref` 会漏）。

### 5.4 `texlate/xlat/` —— 翻译编排（规格：prompt-glossary-spec.md + texglot-patterns.md §7）

- 6 chunk-kind system prompt：公共 C1–C8 + C9 占位符契约（成稿在案）+ C10 人名保留；kind 子句追加；占位符条款永远最后。
- 术语表：三级 + `add_placeholder` 恒等注入 + doc 级过滤烘进稳定 prompt（Anthropic cache_control 友好）。
- 批量：编号 `(n)` 协议 + `@@` 兜底 + 折半梯子；BatchMismatch 不再按行硬切。**批阈值按 E20 实测放宽**：<300 字符/≤2000 批过保守（≥300 chunk 占 34% 全单发，prompt 摊销占输入 68%）——全量 chunk 入批、单批按 token 控 ~2000–4000（≈≤8000 字符）→ 请求数再降 ~10×、总 token 降 ~40%；超大原子 chunk 先切分再入批（§5.2 缺口②）。
- 重试阶梯：整段×2（`previous_validation_error`/`slot_validation_failures` 字段化反馈）→ 行级修复 → slots JSON（`response_format json_object`，8 槽/批）→ 三振 `fallback_orig` 记 warning → `partial`。
- LLM-judge：未知 env 判可译性（temp=0、True/False、6 few-shot、fail-open=True）。
- `recover_copied_tokens`：模型把受保护原文抄回时，唯一出现才换回 token。
- HTTP：状态码分类表 + `retry_delay` 读 Retry-After + `redact()` provider 无关脱敏。
- **本地默认后端（E21/E22 实测，338 调用大样本）**：`http://127.0.0.1:3003/v1/chat/completions` + **`swe-2-medium`** + temp 0.2（free tier 主推：硬契约 **100%（80/80）**、reasoning p50=98 字符、5.9s/chunk、promo→2026-10-16）；备选 `swe-2-high`（99%）；窗口期快选 `glm-5-2`（91%、~4s、promo→09-16）；`swe-2-max` 留修复器。**免费判定唯一事实源 = `/panel/api/models` 的 `cost_tier=="free"`**（无美元价+promo 限时，全网关仅 6 个）——client 启动时拉它与 `/v1/models` 求交 + 探活白名单。硬约束：①**每请求 ~160–566 隐藏 prompt token 开销**（网关注入 agent 系统提示，按型号分档）——E20 的 400 tok/请求摊销上调，且按请求计批内摊不掉；②reasoning 档 `reasoning_content` 吃 max_tokens，**effort 旋钮是模型名后缀**而非参数；③清单≠可用（OpenAI 系全 502、未知名 400）。付费质量对照：glm-5-3-low（$1.4/$4.4 per M）/sonnet-5-medium。

### 5.5 校验链（规格：validator-rules.md + validator-ts.md）

- L0（stdlib，always-on）：占位符多重集 diff+lev≤2 修复建议 / brace 相对平衡 / env 名配对 / cite-ref-label-bib key 集合 diff（含 `\cite{a,b,c}` 逗号拆分）/ math 定界计数 / 长度比+CJK 占比 sanity / 幻觉宏名单——**全部 src↔zh 相对判定**。**E21 实测两盲区补修**：①宏名单只查 zh *新增*命令，丢失型非结构命令不报（sonnet 删 `\` 控制空间未 flag）→ 加"src 命令多重集 ⊆ zh"方向检查（至少覆盖 `\`/`\,`/`\;`/`~` 类脆弱间距命令）；②长度比下界 0.3 恰压正常 CJK 压缩线（0.30 实测误报）→ 放宽到 ~0.25。**E22 大样本再修**：③占位符**严格序守恒降软信号**（73 处违例 ~95% 是 `of X`→`X 的` 合法中文换序，splice 不伤）——硬判据只留"结构占位符脱离文本位"（BIBITEM 类）；④`cs_dropped`（脆弱命令计数差）升硬判据——本轮抓到全部真编译炸弹（`\`+中文熔成 `\和` 未定义 cs）。
- L1（`texlate[ts-validator]` 可选）：validator.js 批处理 JSONL；**必须 baseline 相对模式**（73.7% 真实文件自带 grammar ERROR）；已知 grammar 坑四个（`\end` 改名不报 ERROR 等）已在实现内覆盖。
- L2：编译 log `!` 行 + `l.N` 行号 + paren 文件栈（fixloop parse_log 增强版）。**错误计数双格式**：`^!` + `file:line:`（E10 实证：只数 `!` 会漏掉全部引擎级错误）。
- 不过 → 重译该块（带错误描述进反馈字段）→ 再不过 → fallback 原文。

### 5.6 `texlate/compile/` —— 归一化 + 注入 + fixloop（规格：fixloop-rules.md + texglot-patterns.md §1）

- `normalize.py`：visible_tex 遮蔽（verbatim/comment/\verb 变等长空格、`\n` 保留→行号不变）定位，编辑列表逆序回放；手术清单见 §3-16。
- `inject.py`：锚点 = `\begin{document}` 前（兼容块）+ `\documentclass{}` 后（字体系块）；`\documentstyle` → 拒绝注入；ctex 冲突签名 → xeCJK 路径；FLOAT_SIZING 仅在有 figure/table 时注入；TABLE_FITTING hook threeparttable。
- `engine.py`：Engine 协议（caps/compile/probe_file/install_file/rebuild_fontmaps/filemap）；xelatex `-no-shell-escape -halt-on-error -file-line-error -recorder`；tectonic `-X compile --untrusted --keep-logs --makefile-rules --hide secrets`；`--makefile-rules`/`.fls` → compiled_dependencies。
- `fixloop.py`：yaml 驱动（taxonomy 23 行 → 16 规则 + §3-22 新增 9 条/项，phase gate/precheck/loop、每轮一条、dedup、stuck×3、order 900 LLM 兜底）；`ctan_fetch` = tlpdb 离线索引（8148 包/138K 文件、0.14s 构建）+ tlnet archive 解包 + cwd 平铺遮蔽（E19 实测成立），**仅限 TeX 输入层文件**——物理字体/EPS 走改写规则；`soul_cjk_mbox` 覆盖缺口是沉淀队列头号 case；`undefined_cs_guess` 需 cs→pkg 知识库（fdsymbol/stix/unicode-math 符号包映射）。
- 兜底顺序：tectonic（0.5–90s，热缓存 ≤22s）→ 失败/可疑降级 → xelatex+fixloop；引擎失败集实测几乎互补（联合 clean 9/12）。
- 沙箱：env 白名单 + `openin_any=p` + sandbox-exec（mac）+ `killpg` 进程树 + timeout。
- 判定：clean = 有 pdf 且 log 错误 ≤3（双格式计数）**且无 `Invalid UTF-8 byte` warning**（latin-5 静默污染盲区，E9）**且中文实际进 PDF**（`Missing character` 计数==0 或 PDF 字体表含 CJK——E10 F6：hep-th 出 8 页 pdf~ 但 0 中文字节，是全线最坏静默失败）；`partial`=有 pdf 但 dirty。
- fixloop 缺包通路（E10 F8 实测）：四类缺文件正则 → `tlmgr search --global --file` → `tlmgr --usermode install`（21 种装入 `~/Library/texmf`）；`not relocatable` 落兜底分支（`.ins` 手工生成/放弃标记）；搜索缓存落盘。

### 5.7 `texlate/server/` + `web/` —— API/队列/前端（规格：web-layer.md）

- 5 表 DDL + 11 态机 + SSE 协议（snapshot/stage/chunk/log/warning/error/done，200ms 合帧，`Last-Event-ID` 重放）照规格实现。
- BYOK 四级入口：header > settings.json(0600) > env > CLI configure；key 只活内存，`tenant='k_'+sha256(key+salt)[:12]`；四层脱敏防线。（勘误 2026-09-17：**server 形态 key 不回落**——`TEXLATE_MODE=server` 且无 `X-Texlate-Key` 时 `resolve_auth` 直出 `api_key=""`/`source=none`，不落 settings.json/env，固定匿名桶永不携带部署方凭据（读面同此）；`validate_model` 加 `isprintable` 闸拒 C0/C1/分隔符族控制字符。）
- 中间件：TrustedHost(localhost) + 非 GET 校验 Origin/Sec-Fetch-Site + `/api` no-store——本地持 key 服务必须防 CSRF。（勘误 2026-09-17：impl 为单中间件 `request_gate_mw` 两形态共用——local 形态 `Host` 剥端口须 ∈ `{localhost,127.0.0.1,::1}` 违则 403（DNS rebinding 收口，含读面全请求）；mutating `/api`（POST/PUT/DELETE/PATCH）按序：`Origin` 命中 server `cors_origins` allowlist 放行 → `Sec-Fetch-Site: cross-site` 403 → `Origin` 在且 scheme+netloc（含端口）≠ 请求 scheme+`Host` 403（loopback 族内跨端口同拒）→ 两头皆无放行（非浏览器客户端）；server 形态无 `X-Texlate-Key` 的 mutation 一律 401 `auth_required`，allowlist 命中不豁免。旁闸：非空 JSON body 须 `Content-Type: application/json`（容 charset）违则 415——浏览器 simple-request 造不出合法 mutation；`PUT /api/settings` 与 `settings/test` server 形态 403 关停；`settings/test` body 给 `base_url` 不给 `api_key` → 400（跨槽 exfil 闸）；upload 文件名白名单化后落 `.`/`..` → 400 不留孤儿目录。）
- 前端：三模式 + split 双 PdfPane + SyncEngine（~100 行已成稿）+ 段落棋盘格进度 + HtmlPane 降级（marked+KaTeX，`data-chunk` 1:1 锚比 PDF 锚更准）。
- `dual.json`：alignment（landmarks|pages）+ 可选 chunks 段对。
