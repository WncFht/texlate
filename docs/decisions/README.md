# 决策记录

本目录是 texlate 全部架构与产品决策的叙事面：`background.md` 讲项目缘起（hjfy.top 是什么、原作者结论、texlate 差异化），`adr/` 下 19 篇 ADR 承载全部裁决。每篇 ADR 收敛到**当前生效状态**——历史改判在「演变」节带过，「现状」节与代码对齐；读决策只需读最新状态，不必翻裁决史。

## 体例

- **状态**：`现行` = 当前生效；`已改判(→ADR-XXXX)` = 被后继裁决取代。本篇 ADR 集合中所有条目均为现行生效面——被取代的结论（如 xelatex 主引擎、in-process babeldoc、retry 原地重试）一律记录在宿主 ADR 的「演变」节，不单独占号。
- **日期**：`YYYY-MM-DD（初次裁决）| 更新 YYYY-MM-DD（改判/增补）`——只记改结论的日期，不记编辑日期。
- **编号**：按主题聚簇（0001–0007 内核管线、0008–0009 获取、0010–0011 翻译、0012–0018 产品面、0019 登记），不按裁决时间排序。
- 证据一律指向 `research/` 调研档案或主仓 `docs/05` 的 E1–E22 证据矩阵条目；代码对不上的现状标「（未核实）」。

## 与主仓文档的关系

本目录是主仓 `docs/01`–`docs/05` 决策史的对外重写：01 的技术栈选型收敛进 ADR-0001/0019，04 的候选评估沉淀进 ADR-0019 否决表，05 §3 的 22 条裁决按主题合并进 ADR-0002–0018（一条裁决可能被拆进多篇，一篇也可能合并多条——映射在各篇「理由」节注明）。主仓文档保留为历史档案；本文档与代码现状对齐，出现分歧以本文档 + 代码为准。
