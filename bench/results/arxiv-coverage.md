# arXiv 覆盖率实测:LaTeX 源码可用率 vs 官方 HTML 覆盖率

日期: 2026-09-14 · 全部实测,非文献转述

## 方法

- **采样**: 从 arXiv 官方月度投稿统计 (`arxiv.org/stats/get_monthly_submissions`,CSV) 取各月真实投稿数作为 ID 上界,分层均匀随机生成 60 个 ID:2008–2023 每年 3 篇 + 2024–2026 每年 4 篇。ID 格式按年代 (`YYMM.NNNN` 4 位 <2015,`YYMM.NNNNN` 5 位 ≥2015)。404 重抽。
- **源码探测**: `GET arxiv.org/e-print/{id}`(301→`/src/{id}`),读头部魔数:`1f 8b`(gzip → 有源码)/`%PDF`(PDF 直投,无 LaTeX 源码)。
- **HTML 探测**: `GET arxiv.org/html/{id}v1` 状态码;边界个案再查 `html/{id}`(最新版)。
- **源码解剖**: 有源码的全量下载(上限 90MB),解 gzip、列 tar 成员,统计 .tex/.bib/.bbl/.sty/.cls。
- **限速**: 全局 ≥3.05s/请求,共 ~170 请求,零 429。

## 覆盖率矩阵 (n=60)

|  | 有 HTML | 无 HTML |
|---|---|---|
| **有 LaTeX 源码** | 51 (85.0%) | 1 (1.7%)¹ |
| **无源码 (PDF 直投)** | **0 (0%)** | **8 (13.3%)** |

¹ 唯一个案 2605.15481:`html/{id}v1` 404 但 `v2` 200(v1 渲染失败、v2 成功)。**按"任一版本有 HTML"计,源码论文的 HTML 覆盖率 = 52/52 = 100%。**

- 有源码: **52/60 = 86.7%** (Wilson 95% CI ≈ 76%–92%)
- 有 HTML(v1): 51/60 = 85.0%;按最新版: 52/60 = 86.7%
- 本样本中 **HTML ⟺ 源码 完全等价**: arXiv HTML 由 LaTeXML 从源码生成,PDF 直投无 HTML。HTML 通路**不是**对无源码论文的补充。

## 分年代趋势

| 年代 | n | 有源码 | PDF 直投 | PDF 直投率 |
|---|---|---|---|---|
| 2008–2014 | 21 | 21 | 0 | 0% |
| 2015–2021 | 21 | 15 | 6 | 28.6% |
| 2022–2026 | 18 | 16 | 2 | 11.1% |

- PDF 直投是长期稳定存在的少数派 (~13% 总体),2015–2021 段略高;每年 n=3–4,单年噪声大,但三个年代桶的差异方向清晰:**老论文几乎必有 TeX 源码**(arXiv 起家于物理社区,Word/PDF 直投是后来生态多样化才增多的);新论文源码率回升(~89%)。
- PDF 直投的 8 篇全部是正常发表论文(抽查 abs 页确认非撤稿),分散在 1507/1602/1702/1802/2012/2109/2501/2512。

## 源码结构 (52 篇有源码)

| 维度 | 实测 |
|---|---|
| 打包形式 | tar 多文件 44 (84.6%) · 单文件 .tex.gz 8 (15.4%) |
| 文件数 | 中位 7 · 均值 11 · 最大 80;1 文件 15%,2–10 文件 52%,11+ 文件 33% |
| 自带 .cls/.clo | 20/52 (38.5%) — 自定义类文件很常见(ptptex.cls, pnastwo.cls, arximspdf.cls, iopart…) |
| 自带 .sty | 10/52 (19.2%) |
| 含 .bbl(预烘焙参考文献) | 25/52 (48.1%) |
| 含 .bib | 15/52 (28.8%);其中 bib+bbl 12,**仅 .bib 无 .bbl 3 (5.8%)** |
| **.bbl 无 .bib** | 13/52 (25%) |
| 两者皆无 | 24/52 (46.2%) — 内嵌 `thebibliography` 或无参考文献(文件列表见图+tex) |

分年代:`.bbl` 随年代增多(08–14: 4/21 → 15–21: 11/15 → 22–26: 10/16);`.bib` 同趋势(0/21 → 5/15 → 10/16)——新论文更常带完整 bib 数据。

## 补充:bench/corpus/ 实测(40 篇源码目录)

- 有 .bbl: 23/40 (57.5%) · 有 .bib: 12/40 (30%)
- **有 .bbl 无 .bib: 17/40 (42.5%)** — 与全站抽样(25%)同向、更高;corpus 偏老论文
- 两者皆无: 10/40 (25%)

含义:真实世界里 **~一半论文自带 .bbl**,编译路线无需跑 bibtex;仅 ~6% 是"只有 .bib 需要现场跑 bibtex"的情形;~46% 连 .bbl 都没有(内嵌 thebibliography)。**翻译管线应直接读 .bbl/内嵌文献块,不要假设能拿到 .bib。**

## 对翻译产品路线的结论

1. **纯 LaTeX 源码路线覆盖 ~87% 论文**(本样本 52/60;老论文近 100%,总体 76–92% 置信区间)。多文件 tar 是主流(85%),必须做 `\input/\include` 展平;38% 自带 .cls/.sty,宏环境复杂但都在包内自洽——**解析型翻译(不编译)即可吃这 87%**。
2. **arXiv HTML 通路不能救无源码论文**(覆盖集合与源码集合完全重合),但它是**同类覆盖下的异构降级**:LaTeXML 能扛我们手写解析器会崩的怪宏(本样本中 LaTeXML 失败率 ≈0/52,仅 v1 单版本失效)。建议:`LaTeX 解析失败 → arxiv.org/html/{id}` 降级(取最新版,勿只试 v1),输入换成结构化 HTML 再翻。
3. **PDF 直投 ~13% 是唯一的"必须走 PDF"人群**——HTML 不存在、源码不存在,只有 MinerU/PDF 提取一条路。若产品要宣称"任意 arXiv ID 可翻",PDF 通路不可省;若只做 LaTeX 路线,需明确告知 ~1/8 论文不支持。
4. **推荐降级链**: e-print 源码 →(解析失败)→ arXiv HTML 最新版 →(无源码/无 HTML)→ MinerU PDF。三层叠加覆盖 ≈ 100%,第一层即已覆盖 ~87%。
5. 参考文献处理按实测分布设计:优先消费 `.bbl` 或内嵌 `thebibliography`(共 ~94% 有文献的源码论文可零成本拿到渲染好的条目),`.bib`+bibtex 现场编译只是 6% 的边角。
