== --rerun 格式验证 ==

- stagerun.py 的 --ids 走 stagerun_lib.select_ids：逗号分隔、逐项 strip、与 manifest e["id"] 比对（want−have 不剔除仍传入）。所以 id 必须用 manifest slash 形；work/<dir> 的 -- 形是 benchlib.safe_id 的 /→-- 目录映射，只出现在文件系统层。
- tmp/rerun-wave.sh --ids-file 接受每行一个 id（逗号分隔也行，空白/# 注释行忽略），内部按 compile 末条分类后同样拼 CSV 喂 --ids——本 rerun_ids.txt 两路都兼容。
- 108/108 在 manifest（layers core,booster,hot,expand 共 5135 条）内且在盘 work/<safe_id>/；0 格 records 有记录但 work/ 缺。
- fixloop --on 可选性（compile 末条 upstream=mock arm=zh 分类）：fail 5 + partial 20 + clean 83，norecord 0、unrunnable(reject/skip/error) 0 → --on all 一批全覆盖，无 rerun-wave.sh 头注所述选不中格。

== 核验过的命令行 ==

segmenter 层修复须全链 parse→xlat→compile→fixloop（zh/ 由 parse 重建、xlat 就地重译、compile 重建 splice、fixloop 收尾）：

  IDS=$(tr '\n' ',' < bench/results/illegal-unit-wave-2026-09-17/rerun_ids.txt | sed 's/,$//')
  D=bench/results/stagerun-loop1-2026-09-16
  uv run python bench/py/stagerun.py parse   --dir "$D" --rerun --layers core,booster,hot,expand --jobs 8 --ids "$IDS"
  uv run python bench/py/stagerun.py xlat    --dir "$D" --rerun --arm mock --layers core,booster,hot,expand --jobs 8 --ids "$IDS"
  uv run python bench/py/stagerun.py compile --dir "$D" --rerun --arm zh --xlat-arm mock --layers core,booster,hot,expand --jobs 8 --ids "$IDS"
  uv run python bench/py/stagerun.py fixloop --dir "$D" --rerun --on all --xlat-arm mock --layers core,booster,hot,expand --jobs 8 --ids "$IDS"

尾部 compile+fixloop 两阶段可走 bash tmp/rerun-wave.sh --ids-file bench/results/illegal-unit-wave-2026-09-17/rerun_ids.txt --stage chain --dir "$D" --xlat-arm mock --go（脚本内部做同样的 compile-末条分类与 --ids CSV 拼接）；但它不覆盖 parse/xlat——本波前两阶段不可省。records 单写者纪律：同结果目同时只允许一个 stagerun 进程。
