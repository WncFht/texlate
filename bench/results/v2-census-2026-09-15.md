## `\if*`/`else`/`fi`/`or` 界标工作量（S4）

dispatch 共 **179** 个 if 族 token：`\fi` 79、`\ifx` 55、`\else` 14、
`\ifCLASSINFOpdf` 8、`\ifCLASSOPTIONcaptionsoff` 5、`\ifCLASSOPTIONcompsoc` 3、
`\ifthenelse` 3、`\if` 3、`\ificcvfinal` 2，另有 `\ifssec`/`\ifmain`/`\iffinal`/
`\ifcvprfinal`/`\iffloatpage`/`\ifcomment`/`\ifpdf` 各 1。

构成：`\ifx` = 宏对宏比较（`_eval_if` → None → 界标档）；`\ifCLASS*`/`\ificcvfinal`
= 类/包 `\newif` 旗标——单文件口径下类文件不进流、永不注册 → 全部走界标；
`\ifthenelse` 被 gullet `startswith("if")` 捕获当原语、求值失败 → 界标（3 参
宏语法，条件段消费正确）；`\fi`/`\else` = 界标 if 的散件收尾。可求值 if
（40 次，consumed tag `if`）不进 dispatch。界标密度 = 0.6/篇，S4 负担轻。

## 口径与警告

单文件流：`Gullet(tex)` 不带 `root_dir` → 全部 `\input` 解析失败，子文件
token 不进流（生产 flatten 后会更多）。env peek 用 `_env_name` + `unread`
回放，不改行为。warnings：`missing_input` 238、`stray_end` 16、
`unpaired_dollar` 15、`def_parse_fail` 8、`env_mismatch` 1。
